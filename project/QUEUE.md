# 1.0 交付队列（小微企业简化版）

更新：2026-11-03。本文件是 1.0 剩余范围的唯一有序清单：产品范围见
[docs/product-scope.md](../docs/product-scope.md)，现在能做什么见 [STATUS.md](STATUS.md)，
候选验收见 [ACCEPTANCE.md](ACCEPTANCE.md)，已定决定与待确认项见 [DECISIONS.md](DECISIONS.md)。

- **2026-11-03 范围重定义**：1.0 改为小微企业简化版（项目收益 + 现金流），专业财务能力移出当前范围。
  原专业版 30 条队列原样归档到
  [queue-professional-2026-11-03.md](../docs/archive/v1.0-planning/queue-professional-2026-11-03.md)，只读历史，不再作为开工依据。
- 一个条目 = 一个用户可见成果 = 一个票据 = 一个 PR（≤1 天、生产代码 ≤约 300 行，测试随 PR）。
- 排序：先范围确认与核心闭环，再现金/首用/提醒，最后发布底线；同一波次最多 2 条在制。
- 每条完成后把 `状态` 改为 `已交付`，并在 [ACCEPTANCE.md](ACCEPTANCE.md) 当前候选段记录真实证据。
- `遗留任务` 是历史 PH 编号（`project/tasks.json` 只读台账，编号不复用）；`需求` 是
  `docs/archive/v1.0-planning/requirement-trace.json` 冻结的 V1-* 编号。
- 只写真实证据：浏览器/命令演示、必需 CI、独立复核。缺环境写清前提，不用文档或配置冒充通过。
- 整体视觉重设计不在本队列：前端风格重设计已暂停，由另行恢复的 UI 票据承担；本队列只做页面范围、入口收口与功能实现。
- 范围、设计方案与任务依赖见 [docs/product-scope.md](../docs/product-scope.md) §8–§9；波次内条目已按依赖排序（如 Q-33/Q-34 依赖 Q-35–Q-37）。
