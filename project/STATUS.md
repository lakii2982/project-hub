## 怎么做事（新）

流程只有一份：[docs/engineering/light-delivery.md](../docs/engineering/light-delivery.md)。
要点：一条需求 → 一条队列成果 → 一个 PR；每个 PR 自带代码 + 测试 + 必需 CI + 一条真实演示 +
一次独立复核；维护代理在门禁与复核通过后用
`gh pr merge <n> --auto --squash --match-head-commit <sha>` 自动合并，没有人工合并步骤。
每两周一次真实环境候选走查 + ACCEPTANCE 清单；不建规划/契约/收口 PR。
