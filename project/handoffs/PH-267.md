# PH-267 · 导入/期初插件归属与契约决策（ADR 0012）

基线 main=69c0bb4（PH-264/265/266 合入）。纯决策/ADR 片，无产品代码/迁移/scaffold。

## 决定

**方案 A：新建 `pmo_plugins.onboarding` 插件 app**（canonical x-owner=onboarding），承载导入预览/冲突清单与期初批次/覆盖/事件编排；ADR 文件按任务命名 `docs/adr/0012-importing-plugin-ownership.md`（未占 0010 invoicing / 0011 time）。

关键约束（ADR 冻结，实现片落地）：
- manifest 8 字段：id=onboarding、name、version=0.1.0、kernel_api >=1.0,<2、requires={contracts,settlement,cash}、default_enabled=True、capabilities=[]、description。
- 注册：pmo/settings.py（INSTALLED_APPS + PMO_PLUGIN_MODULES）+ pmo_plugins/delivery/urls.py，root 单写；domain_metadata 声明 plugin_id/access。
- 迁移：onboarding 自有 `0001_initial`；不抢 core 0010/contracts 0003/cash 0006/settlement 0005 号。
- 命令：`onboarding.opening_batch.draft.save/v1`、`onboarding.opening.commit/v1` 仅具名服务/浏览器；**不新增 import.* 命令**、不接 PAT/MCP/个人 AI 审批/支付/锁账。
- 预览（PH-256）：只做模板识别/映射/冲突清单，`normalized_commands` 是待执行清单，预览零业务事实/零账本/零来源消费（仅 generic audit）。
- 期初（legacy PH-187–191）：OpeningBatch/Coverage/Event append-only；正式提交逐域调用既有 owner 命令（现金 PH-230、未清 PH-224/232、成本/收入各自 owner），单事务、任一行失败整批回滚、重试幂等；已过账走更正，不另造余额/收入/成本。
- 与既有事实：Organization.opening_cash_cents/PH-230/PH-239/PH-224 不新增余额层；期初事件只记录来源与金额供 owner 消费。
- insights（PH-257）归属**单列**：不并入 onboarding；建议下一规划槽登记独立决策片。
