# PH-103 · 单一主控入口

当前 GPT 对话负责总控。`python -m tooling.ai_delivery` 提供 doctor/tasks/run/status/cancel/recover/assemble；运行默认只输出计划，显式 `--execute` 才读取 Issue、建独立工作目录并调用已接入客户端。任务、白名单、依赖、spec 与验收均冻结自已允许仓库的 origin/main，Issue 仅是不可信补充。

Kimi 编写仓库模块，DSH 提供服务模块初稿但超时，Claude 编写测试初稿，OpenCode 对照真实契约整合测试；总控补齐配置、命令入口和边界修复。DSH 超时不计成功开发证明。最终验证及独立复核结果以 report 和 verification 为准。共享元数据由总控单独写入。

每个 run 保留冻结契约与独立目录；同 UUID 改参数或缺少完整契约记录会拒绝。完整差异包含未跟踪、忽略、删除、模式和重命名两端；缓存排除只适用于普通编译文件，缓存名目录或链接仍检查。合件只收集互斥 scope 的同契约结果；总控在完整任务范围补接线后，当前摘要改变，后续证明须重做。

PH-104 是后续交付门禁任务，负责隔离验收、另一客户端只读复核、PR 和合入核对。PH-107 仍等待 PH-104 后经新链路修复探针，PH-105 才核对真实需求/缺陷演练。当前没有无人值守守护进程、开机启动、发布或生产部署。
