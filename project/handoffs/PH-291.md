## 关键语义

- 全部只读聚合既有 owner 事实/只读接口，不复制 owner 表、不建 insights 第二 owner、不写业务事实/账本/现金/收入/成本/未清。
- 纯度：无写、无审计、无收据、无 session；测试用 CaptureQueriesContext 断言零 INSERT/UPDATE/DELETE，且事实/审计/事件计数不变。
- 缺失语义：onboarding counts/totals=None + `import_preview_persistence_not_implemented`（PH-274 无持久化）；pm 的 cash=None + `cash_not_scoped_to_project`；不显示 0。
- 权限：owner/finance/auditor 全量；pm 仅 visible_projects（合同/结算/收入/工时按项目过滤，cash 显示缺失）；member 拒绝；history_read 使模块停用后仍可只读。
- 派生值：settlement remaining=gross−active cleared（测试 assert 20000 而非输入 50000）；revenue difference=recognized−settled；cash net=in−out；time minutes 单独 `minutes` 字段，不混入金额 `totals_cents`。
- 期间/as_of：`as_of` 不得为未来；`period` 为 YYYY-MM 且与 as_of 取交集；非法值 400。
- 路由：因 spec 白名单不含 domain_metadata.py，在 delivery/urls.py 内以 DELIVERY_METADATA 副本追加路由（history_read），不修改 SDK 门控。
