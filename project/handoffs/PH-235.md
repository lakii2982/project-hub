# PH-235 · projectctl 会话效率命令

按 PH-233 冻结契约交付三个只读命令，全部不改变既有命令语义与门禁：

- `orient`：单次输出会话开场事实——manifest 摘要、活动 handoff 正文、compact ready 列表、AGENTS.md「验收与交付」段 sh 块的验收命令。任一来源缺失返回结构化错误，不猜测。
- `next --compact`：ready 列表只出 id/title/kind/risk/status/milestone/depends_on；默认输出与 BASE 逐字节一致（已实测 diff）。
- `draft-report <id>`：生成报告骨架到 stdout（result 一律 `not_run`，S 级 review required/pending），只读不写文件；pass 仍以实际运行为准。

`command_next` 的 ready 判定逻辑原样提取为 `_ready_tasks`，compact 仅过滤输出字段。

## 给下一个执行者的提示

- 新会话开场现在可以：`projectctl orient` → `projectctl brief <id>` → `draft-report <id>` 起草报告，替代裸读 tasks.json/delivery-status。
- PH-234 的 AGENTS.md 措辞引用的就是这三个命令名；PH-234 实施时以本 handoff 为准。
- 量化收益（冷启动 token、单任务时间）按 PH-233 基线口径在 PH-234 合入后统一复测。
