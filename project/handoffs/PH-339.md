## 阻塞

- **精确白名单缺 `pmo_plugins/insights/migrations/__init__.py`**。Django 5.2 将无 `__init__.py` 的 migrations 目录视为 namespace/unmigrated；插件 SDK 因此报 `migration.models_without_migrations`。按用户指令不越权创建，需规划 PR 把该路径补入 PH-339 allowed_paths（或授权实现片提交该文件）。补入后交付工作树应可复现上述检查。
- 未验证：真实 PostgreSQL 并发/锁、CI Linux/PG、浏览器 1440/390 人工检视、生产/UAT、独立 S review。
- 本片不发 canonical `insights.reconciliation_*` 事件；`ReconciliationRefresh` 收据即内部幂等/历史证据，作为首片限制披露。
- 差异单由 PH-354 issue 派生，`difference_cents` 保持 owner 口径（本片恒 null）；不据此做守恒断言。刷新后不再出现的旧 case 不自动关闭/不自动更正，仅在结果 `stale_case_keys` 列出供人工跟进。
- 项目现金无归属，`cash_net_cents` 恒 null+missing，不混入公司现金。
