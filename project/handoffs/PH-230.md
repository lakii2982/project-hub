# PH-230 现金过账与账户覆盖（草稿→posted、规范事件、只读覆盖）

## 本轮交付

- **过账**：`record_cash_transaction`（私有服务，不暴露 canonical cash.transaction.record/v1）：公司锁、owner/finance、receipt 先行、draft+version 条件更新一胜、occurred_on/posting_period 一致性、未来日/locked_through/关期拒绝；dry_run 零副作用；同 token 重放原结果、改输入冲突。
- **规范事件**：每个 posted 流水恰一条 `cash.transaction_recorded.v1`（source=cash_transaction ref、payload changed_refs=[ref]、posting_event_refs=[]）；generic audit `cash.cash_transaction.posted`（非 canonical）；posted 后不可改/删（模型守卫 + 0003 双实现触发器：仅 draft 可 UPDATE，draft→posted 仅 status/version 变化）。
- **只读覆盖估算**：`cash_account_coverage` 返回 posted_in/out/net_estimate/available_estimate/cleared=0/posted_count/draft_count；as_of 含端点；UI 固定文案“已过账净额估算，非现金余额/可用余额”；不暴露 canonical coverage query。
- **投影/UI**：流水 snapshot/list 增加 status_display、can_post、posted_at（取 audit 时间，无新字段）；详情页“确认过账”表单与 posted 只读；列表状态徽标/筛选；账户列表覆盖估算小计。
- **迁移**：0003_cash_posting_guard（约束改 draft/posted + SQLite/PG 触发器收紧）。
- **治理**：verify_integrity 增加 posted 流水恰一条 canonical 事件、source 一致、日期非未来、draft 不得有 canonical 事件、无会计事件/现金 SourceConsumption。
- 明确未做：AccountingEvent/LedgerPosting/LedgerEntry、分类/分配/核销/退款/更正/转账/导入/期初；不解除 PH-169/170/171 proposed。
