# PH-228 现金事实首片：银行账户、银行流水与往来方匹配（无过账）

日期：2026-10-30。基线：PH-227 规划合入 200a507。分支 feat/PH-228-cash-facts。

## 本轮交付

- 新插件 `pmo_plugins/cash`（manifest requires={}、default_enabled=True）：
  - **FundingAccount**：org-owned 银行账户草稿/激活；name 组织内唯一、masked_identifier、opening_cents=0、opening_on 创建即固定；active 后不可改、不可删。
  - **CashTransaction**：银行流水草稿登记；org+账户+external_source_key 唯一且不随版本变化；direction in/out、gross_cents 1..1e12、payee（unidentified/counterparty/own_account）、evidence≥1、counterparty_id 仅 counterparty 派生；同输入重放原记录、改输入冲突；未来日/locked_through/关期拒绝；仅 draft 可改、不可删。
  - **CashPartyMatch**：identify（counterparty 经 contracts 具名只读、employee 经 core Employee、own_account 经同 org 账户）与 reverse（必须 match_ref+reason、同流水 identify、部分唯一防重复反向）；匹配不改金额/日期/方向。
  - **CashReceipt**：同 token 幂等收据。
- 服务/UI：9 条路由（账户列表/表单/保存/激活、流水列表/表单/保存/详情/匹配）、5 模板、基础导航“现金事实”、财务入口；owner/finance 写、auditor 读、pm/member 拒；CSRF/PRG、键盘/空态/停用态、320–1440。
- 迁移：0001_initial + 0002_cash_guards（SQLite/PostgreSQL 双实现：账户 active 不可变、流水仅 draft 可改且不可删、匹配/收据不可变）。
- 治理：verify_integrity 增加 cash 分支（账户 opening、流水金额/方向/payee、匹配同 org 与 original 一致性）；tasks/manifest/report/handoff/verification/delivery-status。
- 明确未做：AccountingEvent/LedgerPosting/LedgerEntry/收入/成本/应收/应付/未清/Clearance/退款/更正/转账/银行文件导入/期初余额；不写 canonical cash 事件、不写 SourceConsumption。
