## 交付

- **新插件** `pmo_plugins/invoicing`：manifest 8 字段（requires contracts/settlement/cash/management_revenue/costing，default_enabled=False）、自有迁移 `0001_initial`、domain_metadata canonical 路由（list/detail history_read；form/record/allocate/reverse business_read/write）、delivery urls root 单写绑定、settings/PMO_PLUGIN_MODULES。
- **模型**：Invoice / InvoiceLine / InvoiceAllocation / InvoiceReversal / TaxQualification；vendor-aware append-only 触发器（PG 函数 + SQLite 触发器）：仅 Invoice 允许 active→reversed 状态位，其余 UPDATE/DELETE 拒绝；模型 save/delete guard 双重保护。
- **服务**（`services.py`）：`record_invoice` / `allocate_invoice_lines` / `reverse_invoice`——公司锁、request_token 审计收据幂等、期间/锁期、整数分 gross=net+tax、行合计=头、分配合计=行、业务来源（合同批准明细/结算未清项/结算）同 org/同往来方/额度只读派生、部分红冲保 active、全额→reversed、append-only 负值冲销、红票≠退款；**不写收入/现金/账本/未清**。
- **浏览器**：invoice_list/invoice_form/invoice_detail + allocate/reverse 表单，全部走具名服务。
- **verify_integrity**：新增发票分支（头行合计、分配守恒与来源、红冲 signed/状态机、规范事件、无财务事件/来源消费）；探针测试证明分支被触发。
- **audit/规范事件**：generic audit + `invoicing.recorded.v1` / `invoicing.lines_allocated.v1` / `invoicing.reversed.v1` DomainEvent。
