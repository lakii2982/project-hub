# PH-266 · time 插件归属与可计费确认契约决策（ADR 0011）

基线 main=1e4c480（PH-245/PH-263 合入）。纯决策/ADR 片，无产品代码/迁移/scaffold。

## 决定

**方案 A：新建 `pmo_plugins.time` 插件 app**，作为 time 域写 owner；首片只承载 `BillableConfirmation`（客户确认可计费分钟）。见 `docs/adr/0011-time-plugin-ownership.md`。

关键约束（ADR 内冻结，实现片落地）：
- manifest 8 字段：id=time、name、version=0.1.0、kernel_api >=1.0,<2、requires={contracts>=0.1.0}、default_enabled=True、capabilities=[]、description。
- 注册：pmo/settings.py（INSTALLED_APPS + PMO_PLUGIN_MODULES）+ pmo_plugins/delivery/urls.py，root 单写。
- 迁移：time app 自有 `0001_initial`；不改 core 0009/contracts 0002/settlement 0005（避免与 PH-264/PH-265 抢号）。
- `time.billable.confirm/v1` 首片仅具名服务/浏览器工作流；不接 PAT/MCP/个人 AI 审批/支付/锁账。
- `core.Timesheet`/审批事实保持 kernel、只读不复制；`time.timesheet.*` 继续由 core 既有服务承载。
- 只写 BillableConfirmation（+审计+`time.billable_confirmed.v1`）；不写收入/账本/现金/未清/合同模板；合同 confirmed_time、结算、管理收入只读消费。
