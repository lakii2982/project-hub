# PH-270 · insights 插件归属与期间核对/读模型契约决策（ADR 0013）

基线 main=61950e1（PH-268 合入后；task_count 195）。纯决策/ADR 片，无产品代码/迁移/scaffold。

## 决定

**方案 A：新建 `pmo_plugins.insights` 插件 app**，作为 insights 域写 owner（期间核对差异单/只读读模型/指标定义），canonical `x-owner=insights` 一致。见 `docs/adr/0013-insights-plugin-ownership.md`（未占 0010/0011/0012）。

关键约束（ADR 冻结，实现片落地）：
- manifest 8 字段：id=insights、name、version=0.1.0、kernel_api >=1.0,<2、requires={cash,settlement,costing,contracts}、default_enabled=True、capabilities=[]、description。
- 注册：pmo/settings.py（INSTALLED_APPS + PMO_PLUGIN_MODULES）+ pmo_plugins/delivery/urls.py，root 单写；domain_metadata 声明 plugin_id/access。
- 迁移：insights 自有 `0001_initial`；不抢 core 0010/contracts 0003/cash 0006/settlement 0005/costing 0004 号。
- 命令：`insights.reconciliation.refresh/v1`、`insights.reconciliation.case.update/v1` 首片仅具名服务/浏览器；`insights.export.create/v1` 留后续；不接 PAT/MCP/个人 AI 审批/支付/关期工具。
- 只读边界：读模型/差异单只追加，不写账本/收入/成本/现金/未清、不建可编辑余额/第二套账；期间预检只读 AccountingPeriod/locked_through 与既有 owner 具名接口，不执行锁定/关期。
- 与既有 owner：cash/settlement/costing/contracts/management_revenue 只读消费，不复制表；差异金额服务端派生，差异单仅跟踪不自动更正。
