# PH-277 · insights 读模型实现前置：契约与只读口径冻结（ADR 0014）

基线 main=71d5665（PH-274 合入后）。纯契约冻结片（docs-only），无产品代码/迁移/scaffold。

## 决定/冻结

`docs/adr/0014-insights-read-model-contract.md`（编号核验：0014 空闲，未占 0010 invoicing / 0011 time / 0012 importing / 0013 insights 归属）冻结 insights 首片三类只读投影：

1. `period_precheck_snapshot(member, *, period)`：contracts/time/cash/settlement/costing/core 只读 blockers/warnings；零写入、不锁账、不关期。
2. `reconciliation_case_list/snapshot(...)`：严格 canonical `ReconciliationCase`——status `draft/pending/approved/rejected/superseded/closed`；required `source_refs/difference_cents/owner_member_id/resolution_note`；readOnly `case_key/rule_code/coverage_key/snapshot_watermark`。refresh 生成 draft/pending；case.update 仅 draft→pending→approved/rejected→closed；旧快照 superseded；request_token 幂等、并发一胜；分页 200。
3. `project_workbench_summary(member, project_id, *, as_of)`：合同额/已确认收入/成本/现金/未清/预算 ETC，缺失显示 null+missing（不显示 0），metric 引用 canonical `MetricDefinition`。

角色矩阵：owner/finance/auditor 全量；pm 仅管理项目；member 拒绝；模块停用历史只读。
写边界：只读聚合既有 owner 事实 + insights 读模型/核对单；**不写** SourceConsumption/AccountingEvent/LedgerPosting/现金/未清/收入/成本/合同/期间锁定；不新增 canonical schema/topic/command；export 首片不实现。
`MetricSnapshot` 为 insights 内部读模型（非 canonical）；实现片精确白名单与反例已冻结，供 PH-272。
