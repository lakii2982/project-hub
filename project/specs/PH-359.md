# PH-359 · insights 差异单/工作台只读实现首片（PH-339 后续）

## 开工资格、价值与范围

PH-356 规划槽消费；接续 PH-339（insights 读模型实现首片）与 PH-343（insights 实现前置契约冻结）。本片实现只读期间核对差异单与项目/公司工作台投影：issue_code/source_refs/owner/severity、ReconciliationCase 只读/状态历史、预算 ETC 缺失 null+missing；**不做**新业务事实写入、导出、通知、可编辑余额。依赖 PH-339/PH-343 未 done，故 proposed。

## 行为（冻结 DoR）

- 差异单：按 ADR 0014/PH-343 的 case_key 至多一条有效记录，append-only 历史，刷新幂等；不伪造通过。
- 工作台：合同额/收入/成本/现金/未清/预算 ETC 只读聚合；缺失 null+missing，不显示 0；项目/公司范围按角色。
- 权限：owner/finance/auditor 全量；pm 管理项目摘要；member 拒绝；模块停用 history_read；跨 org 拒绝。
- 零写：不建业务事实/不复制 owner 表、不新增可编辑余额；可选 generic audit 不改变业务。
- 明确不做：导出（PH-310）、通知（PH-340）、业务写、新 canonical 实体/topic。

## 模型与字段 / 迁移

- 按 ADR 0014/PH-343 在 insights 插件内落读模型/快照；不改已应用迁移；新表取实际叶。
