# PH-253 · PH-244 verify_integrity saved-event 计数加固：每版本恰一条 saved 事件

## 开工资格、价值与范围

PH-247 规划槽消费；来源：PH-244 独立复核 residual（a）——`verify_integrity` 当前只证明最新 saved-event envelope，未断言“每个 BankCharge 版本恰一条 `costing.bank_charge_saved.v1`”（如被删除旧版本事件或同版本重复事件不会被发现）。依赖 PH-244（done），故 ready。本片只加固 `core/management/commands/verify_integrity.py` 的手续费断言并补损坏探测测试，**不改 PH-244 服务/模型/契约、不改其它 owner 断言、不新增业务行为**。

## 精确交付

- `verify_integrity` 手续费分支增强：
  - 每个 BankCharge 的 saved DomainEvent 数量必须恰等于其 version（draft 与改稿版本一一对应），事件 source 必须为该 BankCharge 的稳定 ref、source.version 必须等于对应 BankCharge version、topic=`costing.bank_charge_saved.v1`、payload.changed_refs=[该 charge ref]、payload.posting_event_refs=[]；缺失/多出/错 version/错 topic/错 envelope 均判 corruption 错误。
  - 追加：同一 (org, cash_transaction_id) 唯一 charge、status 仅 draft（PH-244 冻结范围）、无会计事件/SourceConsumption/成本/未清写入、receipt 与 charge 引用一致——若既有 PH-244 分支已覆盖则仅在报告中说明，不重复断言。
- `tests/test_v1_bank_charge.py`（PH-244 已建）追加损坏探测：删除中间版本事件、复制同版本事件、篡改 source.version/topic、伪造额外 changed_refs 等，均须被 verify_integrity 检测；既有正常路径断言保留。
- `docs/verification.md` 追加本片真实执行条目；report/handoff；`verify_integrity --json` 在新建空库与植入损坏库上的实际输出记录。

## 不适用项

无业务字段/状态机/权限/幂等/迁移/金额口径变化；不改已应用迁移、不改 BankCharge 服务与契约、不改其它 verify_integrity 断言（clearance/classification/bank_charge 既有检查保留并更严格）。

## 精确白名单

执行者可写：`core/management/commands/verify_integrity.py`、`tests/test_v1_bank_charge.py`、`project/tasks.json`、`project/manifest.json`、`docs/verification.md`、`project/reports/PH-253.json`、`project/handoffs/PH-253.md`。

## 验收与反例

```sh
python scripts/projectctl.py check
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py verify_integrity --json
python manage.py test tests.test_v1_bank_charge --verbosity 1
python manage.py test tests.test_projectctl tests.test_governance -v
```

- 金样例：正常草稿/改稿（version=1、2）各恰一条 saved 事件 → verify_integrity ok=true；删除或复制一条事件、篡改 version/topic → 明确 corruption 错误且含 bank_charge 标识。
- 反例：只按最新版本检查（漏检旧版本）、把重复事件当合法、放宽其它断言、跳过空库路径、把测试写成只测 helper 不测命令。
- 空库 `verify_integrity --json` 仍为 ok=true/errors=[]；既有 clearance/classification 断言不回归。
