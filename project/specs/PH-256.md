# PH-256 · 导入预览与冲突清单首片：CSV 模板识别、字段/主数据映射与逐行冲突（预览零账本、无提交）

## 开工资格、价值与范围

PH-248 规划槽消费；来源：1.0 需求 WP-IMPORT（全域模板、预览与幂等原子导入，S6）与 WP-RECONCILE/WP-PROJECT-CLOSE 上游。拟依赖 PH-181（四类核对与差额追踪，proposed）与 PH-185（项目聚合、结项与迟到款，proposed）；依赖未 done，故 proposed。承接导入最小闭环中的**只读预览**部分：CSV 上传 → 模板识别 → 字段/单位/主数据映射 → 逐行冲突清单（ImportPreview/ImportConflict 草稿事实），**不做**正式提交/写业务、不做原子导入、不新增 `import.*` 命令、不改既有业务规则；提交与幂等原子导入留 PH-188 后续片。不解除 PH-187/PH-188/PH-189/PH-190/PH-191 proposed。

## 行为

- **上传与识别**：owner/finance 上传 CSV（仅首片：UTF-8、≤5MB、≤5000 行、表头+数据行；拒绝二进制/超限/空文件）；服务端按已登记模板（项目/合同/现金/费用等，首片至少 2 个模板）识别列并生成映射建议；无法识别/多模板歧义返回明确错误与候选模板，不落业务事实。
- **映射**：字段/单位（元↔分、日期格式、布尔/枚举）/主数据（项目、往来方、账户）按只读字典校验；映射结果须由用户确认后才进入预览（首片允许服务端默认映射 + 用户逐列修正）；客户端不得传派生字段（余额/账本/状态/事件）。
- **冲突**：逐行产出 ImportConflict（必填缺失、类型/单位非法、主数据不存在/停用/跨公司、重复行/文件内唯一键冲突、金额越界/负值、日期未来/锁期/关期、模板列缺失）；预览为纯只读，零业务事实、零账本、零来源消费、零事件（除 generic audit `importing.preview.created`）；预览行数/冲突数与输入一致，可下载/查看冲突清单。
- **幂等/权限**：request_token 预览收据（org+token 唯一，输入 digest），同 token 同输入重放原预览、改输入冲突；预览保留期限由报告说明（例如 24h 或以数据库记录为准）；owner/finance 写预览、auditor 读、pm/member 拒绝；模块停用写拒绝、历史只读。
- **只读**：预览列表/详情/冲突清单；不提供导入执行按钮（提交留 PH-188）。
- 明确不做：正式提交/原子导入/回滚、跨域写入、期初/开账、更正/撤销、导入命令通道、批量外部 API、模板编辑器、附件/非 CSV 格式、导出。

## 模型与字段

- `ImportPreview`（importing 新增，草稿事实）：org、template_kind、file_sha256、row_count、status（draft/expired；首片不产生 applied）、mapping JSON、conflict_count、created_by、created_at、request_token 唯一收据。
- `ImportConflict`（importing 新增，append-only）：preview FK、row_no、column_key、conflict_code、message、raw_value；不写业务实体。
- 迁移：importing 按实际叶节点下一号；SQLite/PostgreSQL 双实现触发器禁改删预览/冲突（或按草稿语义仅允许过期标记，报告披露）。
- **前置决策点（不在本片决定）**：importing 是否新建独立插件 app、还是承载在 delivery/既有 app 内，必须先在 PH-181/PH-185 规划或独立规划 PR 确认（含插件 manifest/requires/迁移 owner/路由归属）；本片不预设新建 app、不自造 SDK/插件契约；未确认前保持 proposed/blocked。
- 不建可编辑余额/第二套主数据；模板/字典只读复用既有 owner 具名接口。

## 验收与反例

```sh
python scripts/projectctl.py check
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test tests --verbosity 1
python manage.py verify_integrity --json
```
