# PH-281 · 成员账号/项目范围与授权审计只读运营视图首片（无写入口）

## 开工资格、价值与范围

PH-278 规划槽消费；来源：PH-264（成员账号生命周期与项目范围首片，done）、PH-024（基础资料唯一维护服务与权限边界，done）。承接 1.0 运营核对缺口：为 owner/auditor 提供**只读**的成员账号/角色/项目范围/AgentToken 生命周期与授权审计视图，便于核对越权、停用、跨项目可见性与令牌撤销；**不做**账号/角色/范围/令牌写操作、不改 core 身份事实、不新增 canonical 事件/命令、不做迁移。

## 行为（冻结 DoR）

- **只读接口**：
  - `member_access_snapshot(member, *, as_of=None)`：返回 org 内成员列表（脱敏字段：member ref、display_name、status、roles、项目范围 refs、agent token 计数/最近签发撤销时间），分页上限 200/页；pm 仅其管理项目成员摘要（不含他人薪资/费率/凭据）。
  - `member_access_audit(member, *, member_id=None, since=None, as_of=None)`：返回账号/角色/项目范围/令牌相关审计事件摘要（action、actor、target、时间、结果），只读。
  - `member_access_issues(member, *, as_of=None)`：异常清单（重复 active 绑定、跨 org/项目范围错位、停用成员仍持有效令牌、角色与范围不一致、过期令牌未撤销、审计缺口）。
  - 全部只读派生（复用 PH-264/PH-024 已交付服务与审计事件，不复制身份表、不建可编辑投影）。
- **权限/门控**：owner/auditor 可读全量；pm 仅其管理项目的成员摘要；member 拒绝；identity/core 模块停用后历史只读可读；未登录 403；不返回密码哈希/token 密文/薪资费率。
- **幂等/审计**：只读接口无副作用、无收据；可选 generic audit `core.identity_access.viewed`（actor/org/as_of），不含明细。
- **明确不做**：成员创建/停用/角色变更/项目范围变更、AgentToken 签发/撤销、邀请/SSO/密码策略、写/迁移/canonical 事件、导出文件、跨公司数据。

## 模型与字段 / 迁移

- 首片**不新增业务表/迁移**：按请求只读派生；不改 core 已应用迁移（叶 0010）。
- 复用 PH-264 成员/范围事实与 PH-024 权限边界、既有 DomainEvent/审计只读；不复制身份表为可编辑余额。
