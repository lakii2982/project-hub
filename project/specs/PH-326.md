# PH-326 · 多币种汇率快照实现与历史展示后续（汇率 owner 落表/历史）

## 开工资格、价值与范围

PH-323 规划槽消费；来源：PH-324（canonical 币种扩展，ready）、PH-321（多币种实现首片，proposed）、PH-214/PH-224（done）。本片在 PH-324/PH-321 之后实现汇率快照的持久化/历史与只读展示深化：FXRateSnapshot 落表（日期/来源/精度/版本/审计）、换算 ref 追溯、同业务日期多版本/缺汇率 issue；**不做**汇兑损益、外币现金账户、多币种账本、发票税额。依赖未 done，故 proposed。

## 行为（冻结 DoR）

- **汇率快照**：owner/finance 维护；append-only 版本化（同基币/报价币/业务日期至多一条有效，纠错=superseded 新版本）；精度/来源/证据冻结；历史不可改。
- **换算引用**：业务事实记录 fx_rate_ref；缺汇率/日期晚于业务日期/跨 org 汇率 → missing + issue，不猜测。
- **只读展示**：历史汇率列表/详情、按事实反查换算来源、对账。
- **权限**：owner/finance 写；auditor 只读；pm 仅项目摘要；member 拒绝；模块停用 history_read。
- **幂等/期间**：request_token；公司锁；dry_run；不改已 posted 业务事实。
- **明确不做**：汇兑损益、外币现金账户、多币种账本、发票税额、外部汇率 API。
