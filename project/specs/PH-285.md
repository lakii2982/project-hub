# PH-285 · 核对底稿只读导出首片：结算/收入/现金核对清单的授权 CSV 导出（无写入口）

## 开工资格、价值与范围

PH-282 规划槽消费；来源：1.0 需求 WP-EXPORT（授权导出与核对底稿）与 PH-283/PH-284 只读核对清单。拟依赖 PH-181（四类核对/差额追踪，proposed）与 PH-182（经营指标/缺口/复盘，proposed）；依赖未 done，故 proposed。承接导出最小闭环：owner/finance/auditor 把只读核对清单（结算覆盖、收入配对、现金桥接）导出为带来源与 as_of 的 CSV 底稿，供人工核对/归档；**不做**新的核对计算口径、不改任何事实、不写账本/现金/未清/收入、不实现 ZIP/manifest/加密外发、不做客户门户。

## 行为（冻结 DoR）

- **只读导出接口**：`export_reconciliation_worksheet(member, *, dataset, filters, request_token, dry_run=True)`：dataset ∈ {settlement_coverage, revenue_pairing, cash_bridge}；只读调用对应核对接口，生成 CSV（UTF-8+BOM、表头、来源 refs、as_of、生成时间、行数、合计校验行）；输出经响应流式返回或写入受控临时文件（报告说明），不持久化业务表。
- **授权/脱敏**：owner/finance/auditor 全量；pm 仅其管理项目且不含他人薪资/费率；member 拒绝；导出文件含 refs/金额/状态但不含 token 密文/密码/敏感备注；模块停用后历史只读。
- **幂等/审计**：request_token 收据（org+token 唯一、dataset+filters digest），同 token 同输入返回同一导出内容标识、改输入冲突；每次导出写 generic audit `insights.export.worksheet`（actor/org/dataset/行数/as_of），不写 canonical `insights.export.create/v1`（该命令属 PH-272 后续实现，本片不接通）。
- **一致性**：导出内容与对应只读快照接口在 as_of 上一致；行数/合计校验与接口 summary 一致；不重新计算口径。
- **明确不做**：新核对口径、任何写、账本/收入/成本/现金/未清写、ZIP/manifest/加密外发、客户门户、定时导出、迁移、contract schema。

## 模型与字段 / 迁移

- 首片不新增业务表/迁移；导出收据复用既有 receipt 语义（若无可复用表，以内存 + generic audit 实现，报告说明，不擅自建表）；不改已应用迁移。
