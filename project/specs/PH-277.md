# PH-277 · insights 读模型实现前置：期间核对/工作台读模型契约与只读口径冻结

## 开工资格、价值与范围

PH-273 规划槽消费；来源 PH-270（insights 归属与期间核对/读模型契约决策前置，ADR 0013）的后续：ADR 已决定 insights 域归属，但读模型的投影字段、只读接口名、角色矩阵与差异口径仍需在实现前冻结。依赖 PH-270（ready 未 done；ADR 0013 合入并 done 后本片可晋级）、PH-002/PH-024/PH-235（done）。PH-270 未 done，故本片保持 proposed，blocker 写明待 PH-270 done 后由后续规划槽复核 DoR 再晋级。

本片是**契约/口径冻结片**（docs-only，不实现业务、不建 scaffold、不改 contract schema）：产出 insights 读模型 ADR/契约说明，冻结期间预检、核对差异单（ReconciliationCase）、项目工作台汇总三类只读投影的字段、接口名、角色矩阵、分页/导出边界与「只读、不写事实」约束，并同步 PH-257/PH-262 spec 的 decision point；不写代码/迁移/测试运行逻辑（验收为 check + 治理 + verify-change）。

**不做**：业务实现、模型/表/迁移、contract schema 变更、路由/页面、账本/金额/期间写、写入口、预测覆盖、导出文件格式实现、客户门户。不解除 PH-257/PH-262 proposed。

## 行为（冻结 DoR）

- **归属与接口冻结**：按 ADR 0013 结论写明 insights owner、迁移/路由/门控归属；冻结只读接口：`period_precheck_snapshot(member, *, period)`、`reconciliation_case_list/snapshot(member, ...)`、`project_workbench_summary(member, project_id, *, as_of)`；每个接口声明输入/输出字段（refs、金额整数分、状态、责任人、差额、as_of）、只读角色矩阵（owner/finance/auditor 全量；pm 仅管理项目；member 拒绝）、分页上限与导出边界（本片不实现导出）。
- **口径冻结**：期间预检项（未审批单据/工时、锁账冲突、未清/核销/退款/抵扣覆盖、合同终止/变更影响）与差异单状态机（open/assigned/resolved? 只读展示口径，不写状态）；项目汇总字段（合同额/已确认收入/成本/现金/未清/预算 ETC）与来源 owner 接口；差额符号与舍入口径（整数分，ROUND_HALF_UP）；不新增可编辑余额/桥表。
- **不写事实**：所有接口只读聚合既有 owner 事实；不写 SourceConsumption/AccountingEvent/LedgerPosting/任何业务表；无 canonical 事件/命令新增。
- **同步**：更新 PH-257/PH-262 spec 的 decision point/白名单指向本 ADR 结论；更新 tasks.json blockers（PH-257/262 仍 proposed，缺 PH-180/181/182/183 与 PH-270 done）。
- **文档产出**：`docs/adr/0014-insights-read-model-contract.md`（编号先核号，不得占 0010/0011/0012/0013）；在 docs/v1.0-development/ 适当位置记录只读契约摘要；report/handoff。
