# PH-371 · 税额资格→costing 开放期抵扣成本更正首片（ADR 0015 后续）

## 开工资格、价值与范围

PH-369 规划槽消费；依赖 PH-320（TaxQualification/确认，done）、PH-322（关期/开放期，done）、PH-330（costing 分摊/预算，done）、PH-313（成本前置，done）。本片实现：已确认 `not_recoverable` 税额的**成本影响**由 costing owner 在开放期做差额更正；invoicing 只记录税额资格事实，不写账本/成本/收入/现金。**不做**重实现税额确认、汇兑损益、多币种扩展、税款申报。

## 行为（冻结 DoR）

- **成本更正**：仅 confirmed/not_recoverable 税额可生成 costing 开放期调整；金额=税额（或按 ADR 0015 冻结口径）；append-only 调整事件，引用原 TaxQualification/发票/期间。
- **期间/锁期**：仅开放期；已关期/锁定拒绝；更正留原始来源/业务日期/入账期；不重算历史。
- **幂等/权限**：owner/finance；request_token 收据；同资格重复更正拒绝；公司锁；auditor 只读、member 拒绝、停用 history_read。
- **明确不做**：直接改发票/税额事实、账本/收入/现金/未清写、汇兑损益、多币种扩展、税款申报。

## 模型与字段 / 迁移

- 复用 costing 既有成本调整模型/迁移；如需内部收据由实现片按实际 BASE 申请，不改已应用迁移。
