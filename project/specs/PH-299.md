# PH-299 · 期间关期与预测覆盖（WP-FORECAST/CLOSE）首片：关期前置与预测覆盖契约冻结

## 开工资格、价值与范围

PH-298 规划槽消费；来源：1.0 WP-FORECAST/CLOSE 与 legacy PH-180（期间预检/锁定）、PH-181（四类核对/差额）、PH-182（经营指标/缺口/复盘）（均 proposed）。本片是关期/预测的契约冻结前置：冻结期间预检 blockers 与关期命令边界、预测覆盖（forecast coverage）字段与缺口口径、只读读模型与通知边界；**不做**关期实现、不写账本/期间锁定、不做通知/导出。依赖 PH-180/PH-181/PH-182（均 proposed），故 proposed。

## 行为（冻结 DoR）

- **关期前置契约**：期间预检只读 blockers/warnings（未审批单据/工时、未过账现金、未核销/未对账、锁期外写请求）；关期命令以具名服务/浏览器承载、owner/finance 可执行、auditor 只读；关期后写拒绝、历史只读；不新增 PAT/MCP/关期工具。
- **预测覆盖**：预测批次/期间/版本/覆盖状态（covered/partial/uncovered）字段与缺口口径；覆盖由服务端派生，不接受客户端覆盖；缺失显示 null+missing 不显示 0；不建可编辑余额/第二套账。
- **只读读模型**：项目/公司预测覆盖汇总只读投影，引用既有 owner 事实；不写业务事实、不新增 canonical topic/command（若需新增，另立规划并核号）。
- **权限/门控**：owner/finance 写关期/预测；auditor 只读；pm 仅其管理项目摘要；member 拒绝；模块停用历史只读。
- **幂等/并发**：request_token 收据；公司锁；同期间并发关期一胜；重复关期幂等拒绝。
- **明确不做**：关期实现、期间锁定、通知、导出、账本/收入/成本/现金写、预测算法/机器学习、客户门户。
