# PH-304 · 运营核对底稿授权只读导出首片：核对总览/结算/现金/手续费清单 CSV（无写入口）

## 开工资格、价值与范围

PH-302 规划槽消费；来源：PH-291（跨域只读核对总览，done）、PH-283（结算覆盖只读核对，done）、PH-288（银行/现金余额只读对账，done）、PH-280（手续费只读配对，done）、PH-281（成员/授权只读视图，done）。承接核对底稿导出缺口：owner/finance/auditor 把已交付只读核对结果导出为带来源与 as_of 的 CSV 底稿，供人工复核/归档；**不做**新核对口径、不改业务事实、不写账本/现金/收入/未清、不做 ZIP/manifest/加密外发、不做定时导出。全部依赖已 done，置 ready。

## 行为（冻结 DoR）

- **导出接口**：`export_reconciliation_worksheets(member, *, dataset, as_of=None, period=None, request_token, dry_run=True)`：dataset ∈ {ops_overview, settlement_coverage, cash_bridge, fee_pairing}；只读调用对应只读服务/接口，生成 CSV（UTF-8+BOM、表头、refs、as_of、生成时间、行数、合计校验行）；dry_run 返回计划（dataset/行数/列/校验行）不生成文件；真实导出经响应流式返回（或受控临时文件，报告说明），不持久化业务表。
- **权限/脱敏**：owner/finance/auditor 全量；pm 仅其管理项目行；member 拒绝；文件含 refs/金额/状态但不含 token 密文/密码/薪资费率；模块停用历史只读。
- **幂等/审计**：request_token 收据（org+token 唯一、dataset+as_of/period digest）；同 token 同输入返回同一内容标识、改输入冲突；不写 canonical 事件；按本波约定不写 generic audit（保持零副作用）。
- **一致性**：导出内容与对应只读接口在 as_of 上一致；行数/合计校验与接口 summary 一致；不重新计算口径。
- **路由**：canonical `pmo_plugins/delivery/domain_metadata.py` 声明 `ops-export/`（access=history_read），urls 仅导入；页面 GET 筛选 + 下载，无 POST 写业务。
- **明确不做**：新核对口径、任何业务写、ZIP/外发、定时/邮件、迁移、contract schema 变更、身份敏感明细导出（PH-281 视图不导出 token 内容）。
