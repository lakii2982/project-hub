# PH-026 · Kimi 全站界面与经营趋势可视化

来源：父Issue #41/子Issue #46。先读PH-023 visual-system.md/frontend-standards.md/ui-tokens.css，全部前端只由本机Kimi Code实现；后端趋势与测试交GLM/DeepSeek。依赖PH-023/024/025/022完成后ready，任何已有产品前端只遵循该视觉系统，不引入构建链、远程脚本、字体或新图表依赖。

集中基础资料：/master-data/展示项目、员工、成本费率页签（GET tab白名单、默认projects），独立导航。项目浏览/经营模块只引用，创建/编辑按钮跳基础资料维护入口；旧new/project、new/employee、new/rate与project-edit路由GET导向唯一维护入口，兼容已打开表单POST调用同一服务，无第二套写规则。项目入口按现有visible_projects；员工与费率只owner/finance可读写，其他角色直接请求也拒绝且HTML/context无费率。项目由owner/本项目pm维护；员工编辑/停用、按生效日追加费率不删除历史。组织设置只保留组织/锁账与账户角色配置。

Kimi负责所有模板、样式、原生JS、Django表单字段与文案：沿用PH-025已原子交付的TaskForm/TaskEditForm关键任务关联和TimeForm无task字段，完善字段编排与文案，time表格无任务列；业务模块无基础资料内联编辑。兼容旧POST带estimate_hours可由整合者弃用处理但不影响核算。项目详情沿PH-022保留页签/键盘/图和权限。全站经营总览、项目列表、详情、审批、财务、工时、基础资料、组织设置、导入、助手、Agent连接、插件、审计、登录/密码、错误页统一层级/字体/间距/表格/按钮/反馈，不塞无时间语义的装饰趋势图。

趋势core/trends.py只读，使用LedgerEntry按occurred_on聚合：最近12个月每月成本（含冲销）、实际流入/流出（费用付款不重复成本）；13周预测复用cash_forecast，逾期不移动到本周，明确实际与预测。dashboard/finance有相同来源趋势图与可展开数表；项目页沿用成本预算余额图；项目列表可保留少量主要值，工时按有权限的本人/管理范围提供近8周整数分钟趋势（不新增个人费率或人员成本数据）。零数据用空态、负值/冲销坐标完整，不混淆净现金流、利润、银行余额。金额聚合整数分，SVG坐标Decimal，禁float金额；图表轴/单位/图例/摘要/可访问标题，纵轴保留负值。共享core/charts.py在PH-022已实现可复用。

授权项目集在服务器过滤后才聚合；member/viewer不得从HTML/context/数据属性拿财务图数据，pm只看自己有财务权的项目。core/views/pmo urls/共享接线由主控单写，执行器不互相覆盖；Kimi可写templates/static/core/forms，另一执行器只写trends/tests。必须先写非财务泄漏、跨组织、冲销/成本现金分离、逾期预测、无任务工时、基础资料路由/权限等反例。

验收五条+真实浏览器逐页1440/390px；项目切全部页签、深链/刷新/后退与键盘，移动页签条局部滚动，页面无横溢；基础资料创建/维护与引用、工时提交/审批、表单错误可见。全站检查表记入verification/report，可存脱敏演练截图docs/screenshots；自动化通过不等于审美验收或生产验证。S级独立执行器复核最终差异，当前CI全绿后PR合入，不部署/发布。
