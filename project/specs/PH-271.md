# PH-271 · 导入预览实现首片：CSV 模板识别、字段/主数据映射与逐行冲突（预览零账本）

## 开工资格、价值与范围

PH-268 规划槽消费；来源：1.0 需求 WP-EXPORT/WP-OPENING（legacy PH-187–PH-191、PH-256 导入预览）。PH-267（导入/期初插件归属决策）已登记 ready 但**未 done**，PH-181（四类核对/差额）与 PH-185（项目聚合/结项）仍 proposed；本片按 DoR 保持 proposed，写清精确 blockers。承接导入最小只读闭环：上传 CSV → 模板识别 → 字段/单位/主数据映射 → 逐行冲突清单与预览，**不提交、不写账本/来源消费/现金/未清**；正式提交留后续片。

依赖（blockers）：缺 PH-267 done（owner/迁移号/入口门控未决，决策前不得建 scaffold）；缺 PH-181/PH-185 done（导入提交与期初前置的上游核对/结项能力）。本槽不虚假晋级。

## 行为（冻结 DoR，待 blockers 解除后执行）

- **导入预览**：owner/finance 上传 CSV（UTF-8/GB18030 可识别、≤5MB、≤5000 行），服务端识别声明模板（`time`/`expense`/`plan`/`opening` 四种之一，未知模板拒绝）并解析表头；字段/单位/主数据映射（项目 code、员工/往来方名称、期间、金额单位元→分、工时小时→分钟）由服务端按既有主数据解析，歧义/未匹配/重复列写入冲突清单。
- **逐行冲突**：每行给出 `row_no、severity(error/warning)、field、code、message、raw_digest`；冲突不静默丢弃；预览结果落 `ImportPreview`/`ImportConflict`（canonical 实体，append-only）与幂等收据；预览**零账本、零来源消费、零现金/未清/收入/成本写**。
- **模板/映射**：模板定义与字段别名在服务端冻结；未知列默认拒绝（可在预览报告列为 warning），不得静默忽略金额/日期/主数据列；单位换算整数分/整数分钟，禁 float/bool。
- **权限/门控**：写 owner/finance；auditor 只读预览；pm/member 拒绝；importing 模块停用写拒绝、历史只读；文件内容不落附件库（仅 digest + 冲突/预览投影），报告披露。
- **幂等/并发**：request_token 收据（org+token 唯一、输入 digest＝文件 sha256+模板+映射版本）；同 token 重放原预览、改输入冲突；公司锁；并发上传不产生重复预览事实。
- **明确不做**：正式提交/写入任何业务域、期初建账（PH-267 决策后另片）、自动修正主数据、附件上传、Excel/多文件、增量重试、通知。
- **canonical 边界**：导入预览无独立 canonical 命令/事件（契约未定义 import 命令），仅 generic audit `importing.preview.created`；预览不写 canonical 事件；报告披露。

## 模型与字段（实现 PR 按 PH-267 ADR 决策后细化）

- `ImportPreview`（canonical 实体）：org、template、file_name、file_sha256、status(draft/previewed)，summary JSON（总行/错误/警告）、created_by/created_at、request_digest；append-only。
- `ImportConflict`：preview FK、row_no、severity、field、code、message、raw_digest；append-only，不可改删。
- 迁移：实施时按 PH-267 ADR 决定的 owner 新建 app 自有 `0001_initial`（或复用 owner 下一号），不改已应用迁移；SQLite/PostgreSQL 双实现触发器（禁删/禁改）。

## 服务（实现时冻结）

- `preview_import(member, *, file_name, content, template, request_token, dry_run=True)`：公司锁、fresh 角色/模块；解析+映射+冲突；预览事实与收据；dry_run 零写。
- `list_import_previews/get_import_preview` 只读投影（含冲突分页）。
- 浏览器：上传表单/预览详情/冲突表；五角色/键盘/空错停用。

## 权限与拒绝

写 owner/finance、读 owner/finance/auditor；pm/member 拒绝；importing 模块停用写拒绝。拒绝：未知模板/表头、超大文件/行数、非法编码、金额/日期/单位非法、未知列、重复列、跨 org 主数据、token 改输入；拒绝零半笔（预览/冲突/收据/审计）。
