# PH-314 · 通知中心/导出归档实现前置：提醒派生与导出归档落地边界

## 开工资格、价值与范围

PH-311 规划槽消费；来源：PH-301（到期扫描/通知中心首片，proposed）、PH-310（导出归档/格式/审计后续，proposed）与 PH-179/PH-183/PH-285/PH-304（部分 done/proposed）。本片在通知与导出契约冻结后收窄实现边界：提醒派生/去重/已读状态、导出归档元数据/格式版本/审计；**不做**实现写业务、不做外部推送/Zip/加密外发。依赖未全部 done，故 proposed。

## 行为（冻结 DoR）

- **通知实现前置**：提醒派生自既有 owner 只读事实；同事实+kind 去重；已读/忽略最小状态；每成员只看自己的提醒；不自动业务动作；无邮件/短信/Webhook。
- **导出归档实现前置**：CSV 格式版本/列顺序/校验行；归档元数据（dataset/as_of/rows/checksum/actor/时间）append-only；导出审计 generic audit；重放同 token 同 checksum；审计失败零半文件。
- **权限**：owner/finance/auditor 全量；pm 仅项目行；member 拒绝；模块停用历史只读。
- **明确不做**：实现/迁移、Zip/加密外发、定时/邮件推送、业务写、客户门户。

## 模型与字段 / 迁移

- 复用既有通知/导出服务；如需内部表由实现片按实际 BASE 申请；不改已应用迁移。
