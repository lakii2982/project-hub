# PH-329 · 下一规划槽：验收实现切片与批次 C 登记

- 里程碑：v1.0.0 / 规划
- 风险：S
- 依赖：PH-328（done）
- 状态：ready

## 目标

在批次 B 实现推进期间做一次规划槽：登记剩余实现切片（发票后续/多币种/关期结项/分摊预算/通知/导入提交/insights 读模型/验收运维），只晋级依赖已 done 的，输出批次 C（验收/运维/部署/恢复/性能）路线，保持 `spec ↔ tasks` 白名单与依赖一致。

## 行为 / 契约

1. 复核所有 open 任务，更新 stale 依赖/blockers（用 done 证据），不得虚假晋级。
2. 登记 3–5 个可执行切片（编号从本槽 max+1 连续，先核号；含 `BUDGET`/`ALLOC`/`CLOSE` 实现、通知中心、导入提交、insights 读模型、M01–M15 验收运维切片）。
3. 写入 ROADMAP「批次 C」路线（验收/运维/部署/恢复/性能），标注依赖映射。
4. 留下一规划槽 ready。

## 反例

- 晋级依赖未 done → 拒绝。
- 登记模糊切片（无白名单/验收）→ 拒绝。
- 占位符（`<PH-x>`、`{tid}`）→ 拒绝。
