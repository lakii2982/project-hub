# PH-379 · insights 差异单/工作台实现首片（PH-339/354 后续）

## 开工资格、价值与范围

PH-376 规划槽消费；接续 PH-339（insights 读模型实现首片）与 PH-354（期间预检只读 API）。本片实现只读差异单/工作台投影消费：期间预检 issue/difference/missing、核对差异单 history、项目/公司工作台汇总；**不做**业务写/新 canonical 实体/导出/通知/可编辑余额。依赖未 done，故 proposed。

## 行为（冻结 DoR）

- 只读聚合 owner 投影（PH-291/283/284/288/280/354/363），不复制表、不改 owner 规则；`difference = expected - actual`，任一侧缺失 null+missing，不用 0。
- 差异单 `case_key` 至多一条有效、append-only 历史、刷新幂等；状态/责任人按 ADR 0014。
- 工作台合同/收入/成本/现金/未清/预算 ETC 缺失 null+missing；角色范围 owner/finance/auditor 全量、pm 项目摘要、member 拒绝；模块停用 history_read。
- 零写（除可选 generic audit）；不发送外部消息；浏览器 1440/390 与 PG 交 CI。
- 明确不做：业务事实写、导出（PH-310）、通知（PH-340）、新 canonical topic、可编辑余额。
