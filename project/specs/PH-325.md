# PH-325 · 发票-结算/收入只读对账与税额资格确认（发票写侧后续）

## 开工资格、价值与范围

PH-323 规划槽消费；来源：PH-252（发票实现首片，ready）、PH-284（收入-结算配对）、PH-283（结算覆盖）、PH-287（条款快照）、PH-293（ADR 0015）。本片在发票登记/分配后提供只读对账（发票↔结算未清↔管理收入↔条款）与税额资格确认（使用 canonical TaxQualification，pending→confirmed，不改账本）；**不做**发票红冲/作废写侧（PH-320）、PDF/邮件、多币种、税额申报。依赖 PH-252 未 done，故 proposed。

## 行为（冻结 DoR）

- **只读对账**：`invoice_pairing(member, *, invoice_id=None, project_id=None, as_of=None)` 返回发票头/行/分配、关联结算未清/核销/收入确认 refs、条款快照 refs、gross/net/tax 对比、issues（未分配/超分配/方向不符/跨 org/跨项目/来源未批准/收入-发票净额差异/税额未确认）、missing[]；全部只读派生，不复制表，不重算金额。
- **税额资格确认**：owner/finance 对 pending/unknown 的 TaxQualification 做 confirmed（recoverable/not_recoverable），append-only（superseded），保留 evidence/decided_on；invoicing 只记录资格事实，成本/税额差额由 costing owner 在开放期更正（ADR 0015/A11）；不直接写账本/收入/现金。
- **权限**：owner/finance 写资格；auditor 只读；pm 仅其管理项目摘要；member 拒绝；模块停用历史只读。
- **幂等/期间**：request_token 收据；同 token 重放；期间 active 未关闭、> locked_through；dry_run 零副作用。
- **明确不做**：新 canonical 实体/topic/command（复用既有 TaxQualification/发票/结算/收入事实）；红冲；PDF/邮件；多币种；税款申报。
