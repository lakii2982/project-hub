# PH-310 · 运营核对导出后续首片：CSV 归档/格式版本与导出审计（只读底稿后续）

## 开工资格、价值与范围

PH-307 规划槽消费；来源：PH-304（运营核对底稿 CSV 首片，ready）、PH-285（核对底稿 CSV 导出，proposed）、PH-181/PH-182（四类核对/经营指标，proposed）。本片在 PH-304 首片之后补充导出归档/格式版本与导出审计（谁在何时导出了哪个 dataset/as_of、内容标识），**不做** Zip/加密外发/客户门户、不重新计算核对口径。依赖 PH-304 未 done，故 proposed。

## 行为（冻结 DoR）

- **归档/格式**：导出文件格式版本（v1 CSV 表头/列顺序/校验行）、内容标识（sha256）、落盘/临时文件边界；归档只存元数据（dataset/as_of/rows/checksum/actor/时间），不存业务明细副本。
- **导出审计**：写 generic audit `delivery.ops_export.created`（不含明细），append-only；审计失败不产生半文件。
- **权限**：owner/finance/auditor 全量；pm 仅管理项目行；member 拒绝；模块停用历史只读。
- **一致性**：归档元数据与导出内容校验一致；重放同 token 同内容标识。
- 明确不做：新核对口径、Zip/加密外发、定时/邮件、业务写、迁移、客户门户。

## 模型与字段 / 迁移

- 复用 PH-304 导出服务与 request_token；归档元数据如需内部表由实现片按实际 BASE 申请；不改已应用迁移。
