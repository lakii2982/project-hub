# PH-369 · 独立工程/交付规划入口

本入口用于后续独立工程改造/交付规划：只做问题定位、独立规划契约/规格/依赖/精确白名单及验证方法，不实施产品业务或工程改造本身、不扩本任务范围。本入口不依赖当前 PH-365 规划槽（PH-365 完成前也可独立受理用户明确授权的工程规划），状态/范围/验收以可信 BASE `project/tasks.json` 为准，proposed 不是开工许可。

## 本轮规划范围

- 依赖达成复核：按本槽 BASE 事实复核批次 C 执行片、剩余 proposed 的依赖/DoR；只晋级依赖全 done 的。
- 剩余 1.0 缺口：按工作包依赖/用户优先级登记下一批薄片；每项须有明确上游 done 证据，否则 proposed 并写清缺口。
- 独立工程改造规划：仅在用户明确授权的新目标下登记；不改变既有门禁/验收命令/报告 schema。
- 下一规划槽：完成时留下新的独立规划入口（新 PH 编号，先核号）。
- 约束：规格/验收不得含未替换任务编号占位符；acceptance 只用可执行命令；不建 scaffold、不改 contract schema、不自扩白名单。
