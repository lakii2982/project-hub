# PH-338 · 发票批量/导入后续：发票导入模板、批量登记与来源分配（按 ADR 0015/PH-252）

## 开工资格、价值与范围

PH-337 规划槽消费；来源：PH-252（发票实现首片，done）、PH-320（发票编排，ready）、PH-274（导入预览，done）、PH-289（导入提交，proposed）。本片在单张发票能力之上提供批量/导入：CSV 模板识别与字段映射预检、批量登记、行/来源分配、冲突清单与原子提交；**不做**新 canonical 实体、真实税务查验、PDF/邮件、多币种。依赖未全 done，故 proposed。

## 行为（冻结 DoR）

- **预检**：模板/字段映射只读预检；错误行含原因/原值/行号；预览不留业务痕迹；权限/期间/锁期与单张一致。
- **批量登记**：复用 `record_invoice`/`allocate_invoice_lines` 服务（不复制规则）；同文件重排/重试幂等（导入键与行号无关）；提交全有或全无（事务/公司锁）；失败回退。
- **冲突**：发票号重复、跨 org/项目、来源未批准/超额、金额不守恒、税额未知等逐条拒绝；可下载错误清单。
- **权限/门控**：owner/finance 写；auditor 读；pm 项目摘要；member 拒绝；模块停用 history_read。
- **明确不做**：新 canonical 实体/命令、税务查验、PDF/邮件、多币种、批量红冲（另立切片）。

## 模型与字段 / 迁移

- 不新增业务模型/迁移；复用 invoicing 与 onboarding 导入服务；如确需内部批次表由实现片按实际 BASE 申请。
