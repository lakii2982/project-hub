# PH-309 · 运营核对工作台聚合首片：只读核对分区汇总与下钻（无写入口、无迁移）

## 开工资格、价值与范围

PH-307 规划槽消费；来源：PH-291（跨域只读核对总览，done）、PH-280（手续费只读配对，done）、PH-281（成员/授权只读视图，done）、PH-283（结算覆盖只读核对，done）、PH-288（银行/现金余额只读对账，done）。承接工作台聚合缺口：把已交付只读核对/总览聚合成单页工作台（分区摘要 + issue 计数 + 下钻链接到各只读页面），**不做**新核对口径、不写业务事实、不做导出（PH-304 独立）。全部依赖 done，置 ready。

## 行为（冻结 DoR）

- **只读聚合**：`ops_workbench_summary(member, *, as_of=None, period=None)` 返回分区（ops_overview/settlement_coverage/cash_bridge/fee_pairing/identity_access）的摘要（issue 计数、关键合计、missing、下钻 URL），全部调用既有只读服务/视图数据；缺失 null+missing 不显示 0。
- **权限**：owner/finance/auditor 全量；pm 仅管理项目摘要；member 拒绝；模块停用历史只读。
- **路由**：canonical `pmo_plugins/delivery/domain_metadata.py` 声明 `ops-workbench/`（access=history_read），urls 仅导入；页面 GET 筛选，无 POST 写业务。
- **幂等/审计**：只读无副作用、无收据；按本波约定不写 generic audit。
- 明确不做：新核对口径、导出、写事实、canonical topic/command、迁移、客户门户。

## 模型与字段 / 迁移

- 不新增业务表/迁移；按请求只读派生；不改已应用迁移。
