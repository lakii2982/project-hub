# PH-244 · 手续费与净额到账拆分首片：银行手续费草稿事实、规范事件与净额对账（批准/成本过账延后）

## 开工资格、价值与范围

PH-242 规划槽消费；来源：1.0 需求 V1-CSH-07（WP-FEE-TRANSFER）。依赖 PH-228（现金事实，done）与 PH-230（现金过账，done）；不依赖 PH-239，不写账本/会计事件/成本。承接 WP-FEE-TRANSFER 第 1 片最小可用部分：在已过账的净额银行流水上登记/修订银行手续费草稿事实（costing owner BankCharge），写已登记的 canonical `costing.bank_charge_saved.v1`，并提供净额/手续费对账只读，使“净到账 + 未批准手续费”可核对。

**本片显式延后（ready 任务不含糊，缺口归入 PH-247 规划槽登记的“手续费审批与成本过账”后续薄片）**：提交/批准/驳回状态机（pending/approved/rejected/superseded）、`core.document.decide` 的 bank_charge handler、成本过账（`costing.cost.post`）、`ReceiptFeeSettlement` 未清核销/关联、`existing_cost_ref` 复用既有成本、counterparty/unconfirmed 手续费承担方、账本/会计事件/现金分类桥接、退款、更正、内部转账、批量、导入、期初。报告与 UI 必须写明“手续费仅登记草稿，未批准、未过账成本、未核销未清”。

## 行为

- **手续费草稿（BankCharge，costing owner）**：owner/finance 对同企业、posted、direction=in 的 CashTransaction 登记或修订手续费草稿。首片固定：`existing_cost_ref` 必须为 null（直接银行手续费）、`fee_bearer` 必须为 company、`scope.kind` 只允许 project（项目范围）、`counterparty_id` 可为 null（费率方未知允许 null）、`tax_cents` 可为 null（未知税额保持 null，不得以 0 冒充）、`gross_cents` 为正整数分手手续费金额且 ≤ 该现金流水 posted gross；`occurred_on`/`posting_period` 必须落在该现金流水日期所属期间且非未来、不得 ≤ org.locked_through、期间必须 active 未关闭；`evidence` ≥1。**状态固定 draft**（canonical 枚举 draft/pending/approved/rejected/superseded 保留，本片只产生 draft；任何提交/批准/驳回请求本片明确拒绝）。**不创建也不修改任何 CashTransaction/账本/成本/未清**。
- **唯一性**：同一企业同一原始银行流水稳定身份（company+cash stable id，排除 BankCharge ID/版本/金额/日期/证据/请求 key）只能有一个 BankCharge；再次保存是同一草稿的新版本（version+1），不建第二笔；业务唯一键不因金额/证据改动而新建。
- **规范事件**：每次草稿保存/修订恰一条 `costing.bank_charge_saved.v1`（source=bank_charge ref（保存后的 version）、payload changed_refs=[charge ref]、posting_event_refs=[]）；同 token 同输入重放原结果且不重复发事件；改输入冲突。generic audit `costing.bank_charge.saved`。
- **净额对账只读**：`net_fee_reconciliation(member, cash_transaction_id)` 返回 posted_net_cents（现金流水 gross）、approved_fee_cents（本片恒 0，无批准路径）、implied_gross_cents = posted_net + approved_fee（即 posted_net）、draft_fee_cents（当前草稿手续费，仅展示、**不计入对账**）、charge_status（draft/无）、reconciled（本片恒 false）；文案写明“未批准手续费不计入对账；对账毛额为派生值，非新现金流水/非应收/非成本”。
- **幂等**：request_token 收据（costing 既有 receipt 模式；新增 BankChargeReceipt 或复用须在报告说明），action=bank_charge.draft.save；同 token 同输入重放原结果、改输入冲突。
- **期间/权限**：写 owner/finance；读 owner/finance/auditor；PM/member 拒绝；costing/cash 模块停用写拒绝、撤权写拒绝；模块停用后历史只读。
- 不新增公开 canonical 通道（`costing.bank_charge.draft.save/v1` 的 browser_workflow_adapter_only 由私有服务/浏览器工作流承载，报告披露；不改 command schema）。

## 模型与字段

- `BankCharge`（costing 新增）：org、cash_transaction_id UUID（跨 owner 无 FK，经 cash 具名只读校验）+ cash_transaction_ref JSON、gross_cents（>0 ≤1e12）、tax_cents（nullable）、existing_cost_ref（本片固定 null）、counterparty_id（nullable）、occurred_on、posting_period、scope_kind='project'、scope_id（project FK/ID）、fee_bearer='company'、evidence JSON(≥1)、status（canonical 枚举 draft/pending/approved/rejected/superseded 保留；本片只产生 draft）、version、created_by、created_at。约束：gross>0；status 枚举；同一 org+cash stable id 唯一；draft 可改稿（version+1），本片无终态/无删除。
- `BankChargeReceipt`（或复用 costing 既有 receipt 模式，报告说明）：org、request_token 唯一、action、input_digest、result、created_by、created_at。
- 迁移：costing 下一号（当前叶 0002，下一号 0003；按实际叶节点生成，root 单写，不抢号、不改已应用迁移）；SQLite/PostgreSQL 双实现触发器。
- 不新增可编辑余额/派生金额列；不建成本/账本/会计事件/未清表。

## 服务

- `save_bank_charge_draft(member, *, cash_transaction_ref, gross_cents, tax_cents=None, counterparty_id=None, scope_kind='project', scope_id, evidence, occurred_on=None, posting_period=None, request_token, expected_version=None, dry_run=True)`：公司锁；fresh 重读角色/企业/现金/期间/既有 charge；校验 posted/direction=in/同 org、金额/期间/锁期/未来、唯一性与改稿版本；dry_run 零副作用；事务内写 BankCharge draft（或 version+1）、generic audit、`costing.bank_charge_saved.v1`、receipt；同 token 重放、改输入冲突。
- 显式拒绝并披露：本片不提供 submit/approve/reject 服务；若浏览器/调用方请求非 draft 状态或批准动作，返回明确“本片未实现批准通道，属后续手续费审批与成本过账薄片”。
- cash 侧具名只读 `posted_cash_for_fee(member, cash_transaction_ref)`（整合者 root 单写于 `pmo_plugins/cash/transaction_services.py`）：返回 posted/direction/同 org/gross/transaction_date/source ref 版本；未 posted/方向不符/跨 org 拒绝。
- 只读：bank_charge_snapshot/list、net_fee_reconciliation。

## 权限与拒绝

- 写 owner/finance；读 owner/finance/auditor；pm/member 拒绝；模块停用/撤权写拒绝。
- 拒绝：草稿/未 posted 现金、direction 非 in、跨 org/项目、existing_cost_ref 非 null、fee_bearer 非 company、scope_kind 非 project、gross≤0/bool/float/超1e12、gross>现金 gross、tax 为负、未来日/locked_through/关期、重复 token 改输入、提交/批准/驳回请求、客户端传状态/审批人/成本/账本/余额覆盖、删除请求。
- 所有拒绝零半笔：BankCharge/receipt/generic audit/canonical saved 事件/现金/账本/成本/未清计数不变（generic audit 与其非 canonical 事件除外）。
