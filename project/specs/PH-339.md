# PH-339 · insights 读模型实现首片：期间预检/核对差异单/工作台只读投影（按 ADR 0014）

## 开工资格、价值与范围

PH-404 规划槽消费：PH-277/291/304/309/343 均 done；PH-343 已冻结 insights 读模型契约（复用 PH-354 期间预检、ADR 0014 差异单/工作台、missing/null、权限）。本片按 ADR 0014/PH-343 实现 insights 插件读模型：期间预检、核对差异单、项目/公司工作台只读投影；**不做**新业务事实写入、不复制表、不做导出/通知。

## 行为（冻结 DoR）

- **期间预检**：只读 blockers/warnings（合同/工时/现金/结算/成本/期间），issue_code/source_refs/owner/severity；零写入（除可选 generic audit）。
- **核对差异单**：canonical ReconciliationCase 投影/刷新/状态更新按 ADR 0014；同 case_key 至多一条有效；append-only 历史。
- **工作台汇总**：合同额/收入/成本/现金/未清/预算 ETC（缺失 null+missing）；项目/公司范围；不建可编辑余额。
- **权限/门控**：owner/finance/auditor 全量；pm 项目摘要；member 拒绝；模块停用 history_read。
- **明确不做**：新 canonical 实体/topic（除 ADR 0014 已冻结）、导出（PH-310）、通知（PH-301）、业务写。
