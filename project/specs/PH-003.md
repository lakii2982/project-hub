# PH-003 · 建立可复验的Linux部署与容器集成验收

状态、风险、依赖和文件白名单以 project/tasks.json 为准。

目标平台先限定Ubuntu 24.04 LTS+Docker Compose v2。一个安装入口检查环境、生成独立密钥、创建持久卷、迁移、启动和健康检查。禁止覆盖既有.env/卷，失败保留诊断并允许重试；不能静默安装系统软件或扩大公网端口。CI用真实Docker/PostgreSQL建空环境并验证重启持久化，失败分支包括端口占用/磁盘不足/镜像拉取失败/迁移失败/旧安装升级。产品初始化向导另见PH-004。离线环境不声称已部署通过。

## 通用退出条件

实际运行本任务验收；提交 project/reports/PH-003.json 与 project/handoffs/PH-003.md。修改金额/权限/迁移/插件内核时独立复核。未执行的检查写入 unverified。不要删除或放宽旧测试；不把 proposed 当作可直接实现的任务。超出基线范围先做规划PR，不能在实现PR中改白名单自我授权。
