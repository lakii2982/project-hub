# PH-318 · 多币种实现前置：币种/汇率快照落地、换算边界与只读展示

## 开工资格、价值与范围

PH-315 规划槽消费；来源：PH-308（多币种/汇率契约冻结，proposed）与 PH-150/PH-155/PH-252（proposed）。本片在契约冻结后、实现前收窄：汇率快照落地（日期/来源/精度/版本）、换算边界（合同/结算/收入/现金/发票）、原币+记账币只读展示与缺失口径；**不做**实现、不写账本/结算/收入/现金、不改 contract schema。依赖未 done，故 proposed。

## 行为（冻结 DoR）

- **汇率快照**：按业务日期冻结、版本化、历史不可改；缺汇率 null+missing（不显示 0/不猜测）；来源可追溯。
- **换算边界**：金额整数分；换算仅在有明确汇率 ref 时发生；舍入 ROUND_HALF_UP；累计/分组规则冻结；不无迁移重算历史。
- **只读展示**：原币/记账币/汇率 ref 同时只读展示；不建可编辑余额/第二套账。
- **权限/门控**：owner/finance 维护汇率；auditor 只读；pm 仅项目摘要；member 拒绝；模块停用历史只读。
- **幂等/并发**：request_token 收据；汇率版本乐观版本；公司锁。
- **明确不做**：实现/迁移、多币种账本、外币现金账户、汇兑损益、发票、导出。
