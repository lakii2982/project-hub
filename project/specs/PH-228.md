# PH-228 · 现金事实首片：银行账户、银行流水与往来方匹配（无过账）

## 开工资格、价值与范围

PH-227 规划候选；拟依赖 PH-214、PH-219、PH-222、PH-224（均 done）。须规划 PR 正常合入可信 BASE、依赖 done 且任务 ready 后才可实现，本文不是开工许可。承接正式 PH-169（账户、银行事实、归属与待匹配）第 1 片，为 PH-170 核销与 PH-171 退款提供稳定的现金事实来源；但过账/分类/可用余额仍属后续片，**本片不解除 PH-169/PH-170/PH-171 的 proposed 状态**。本片只交付“登记真实银行事实并完成往来方匹配”，**不实现现金过账、分类、核销、抵扣、退款、更正、内部转账、银行文件导入、期初余额**；现金账/分类/核销由后续片实现，本文不冒称 PH-169/170 完成或完整 1.0。

## 行为

- **银行账户**：owner/finance 登记 company-owned FundingAccount（name、masked_identifier、account_owner=organization）；草稿可改，owner 激活后不可改；opening_cents 固定 0、opening_on 在草稿创建时固定为该业务日且不可变（期初余额留给期初导入任务，本片不记现金账）。草稿不投影为 canonical FundingAccount 实体，列表/详情标记草稿，canonical 投影与期初余额在后续片冻结。
- **银行流水事实**：登记 CashTransaction 草稿：funding_account、transaction_date（不得未来）、direction in/out、gross_cents（正数整数分）、external_source_key（1..200，组织+账户内唯一，稳定去重）、payee（unidentified 或 counterparty 引用）、evidence（≥1 真实引用）、可选 counterparty（仅 counterparty payee 派生）。重复 external_source_key 同输入返回原记录、改输入拒绝；跨企业/跨账户/超范围拒绝。
- **往来方匹配**：CashPartyMatch 对草稿流水中未识别收款方做 identify（counterparty/employee/own_account）或 reverse；反向匹配需引用原匹配；匹配只改“归属识别”，不改金额、日期、方向、账户，不生收入/成本/现金账/未清。
- **只读**：账户与流水列表/详情、按 as_of 的现金事实查询；owner/finance 写，auditor 只读，pm/member 拒绝；模块停用后历史只读、写路由拒绝。
- 明确不做：AccountingEvent/LedgerPosting/LedgerEntry、收入/成本/应收/应付/未清项/Clearance/Invoice、银行文件上传与模板识别、期初余额、现金余额与 13 周预测。

## 插件与依赖（冻结）

- 插件 manifest：id=cash、version 0.1.0、kernel_api >=1.0,<2、**requires={}（不声明 contracts/delivery 依赖边）**、default_enabled=True、capabilities=[]。Counterparty/Employee 经 contracts 具名只读接口读取，contracts 停用时写入口拒绝；这样不会改变既有测试的插件依赖停用顺序，PH-228 白名单无需包含那 4 个测试文件。

## 模型与字段（严格按冻结契约）

- `FundingAccount`：org、name、masked_identifier、account_owner='organization'、opening_cents=0、opening_on、status(draft/active)、version、created_by、created_at。Unique(org,name)。
- `CashTransaction`：org、funding_account FK、transaction_date、direction(in/out)、gross_cents、external_source_key、payee JSON、counterparty FK nullable、evidence JSON、status(draft)、version、created_by、created_at。Unique(org,funding_account,external_source_key)；gross≤1e12 且>0。
- `CashPartyMatch`：org、cash_transaction FK、action(identify/reverse)、identified_payee JSON、original_match FK nullable、reason、evidence JSON、version、created_by、created_at。
- `CashReceipt`：org、request_token 唯一、action、input_digest、result、created_by、created_at（幂等收据）。

## 服务与状态机

- `save_funding_account(member, *, name, masked_identifier=None, fields, request_token, account_id=None, expected_version=None, dry_run=True)`：草稿保存/更新；organization 固定；dry_run 零副作用。
- `activate_funding_account(member, account_id, *, expected_version, request_token, dry_run=True)`：仅 owner；draft→active；同 org name 唯一。
- `save_cash_transaction(member, *, funding_account, fields, request_token, transaction_id=None, expected_version=None, dry_run=True)`：仅 draft；org+账户+external key 唯一；重复同输入重放原结果、改输入冲突；公司锁内 fresh 重读权限/版本/账户状态；未来日期、非正金额、缺证据、payee 与 counterparty 不一致拒绝；不收金额覆盖/状态/派生字段。
- `match_party(member, transaction_id, *, action, identified_payee, match_ref=None, reason=None, evidence, request_token, expected_version, dry_run=True)`：仅草稿流水；identify 需真实 counterparty/employee/own_account（经 contracts 具名只读接口校验存在且同 org；contracts 停用时拒绝），reason 落 null；reverse 必须给 match_ref（同流水原匹配）与 reason 且不得重复反向；不改金额/日期/方向。
- `cash_transaction_snapshot(member, transaction_id)` / `funding_account_snapshot` / `cash_transaction_list(member, *, as_of=None, status=None)`：私有只读投影（不含 canonical allocated_cents/available_cents；本片不暴露 cash.transaction.get canonical query）。
- 审计：每次写 generic `cash.*` 审计（非 plugin.*，不抑制 outbox）；按既有 core.services.audit 机制会产生非 canonical DomainEvent/outbox，本片不写已登记 canonical cash 事件（如 cash.transaction_recorded.v1）、不新增 registry 条目、不写 SourceConsumption。

## 权限与拒绝

- 写：owner/finance；读：owner/finance/auditor（pm 经项目可见也不能读公司银行事实，除非后续具名授权；本片只 owner/finance/auditor）；member 全部拒绝。
- 拒绝：跨企业、未知/停用账户、非草稿修改、版本过期、重复 external key 改输入、未来日期、transaction_date 早于或等于 org.locked_through 或所在期间已关闭、gross bool/float/≤0/超 1e12、证据缺失、payee 伪造、自审不适用（无审批）、模块停用写路由拒绝、撤权重读。
- 所有拒绝无半笔：FundingAccount/CashTransaction/CashPartyMatch/CashReceipt/LedgerEntry/LedgerPosting/AccountingEvent/Settlement/OpenItem/SourceConsumption 计数不变（generic audit 的审计记录与其非 canonical DomainEvent 除外）。
