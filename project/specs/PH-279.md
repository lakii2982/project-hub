# PH-279 · 现金分类/账本桥接与退款/互转只读核对快照首片（无写入口、无迁移）

## 开工资格、价值与范围

PH-278 规划槽消费；来源：PH-239（现金分类与账本桥接）、PH-240（退款/退回）、PH-244（手续费草稿，仅作无耦合对照）、PH-245（内部互转）、PH-230（posted 现金）、PH-228（账本/claim 契约）均已 done；PH-241 Offset 仍 in_review，不在本片依赖范围。承接 1.0 现金一致性核对缺口：把「posted 现金事实 ↔ 有效分类 ↔ AccountingEvent/LedgerPosting/claim ↔ 退款/退回 ↔ 内部互转撤销」的关系做成**只读核对快照/清单**，供 owner/finance/auditor 检查缺口、重复、金额不一致、跨公司/项目错位；**不做**任何写入口、不改账本/现金/分类/互转事实、不新增 canonical 事件/命令、不做迁移。

## 行为（冻结 DoR）

- **只读核对接口**：
  - `cash_bridge_snapshot(member, *, as_of=None)`：返回 posted 现金的 `transaction_ref`、classification（kind/status/ref）、accounting_event ref/amount、ledger posting refs（book/scope/amount）、claim coverage_key、refund/return totals、internal_transfer link 状态；逐流水或按账户/期间分页（上限 500/页）。
  - `cash_bridge_issues(member, *, as_of=None)`：返回异常清单（分类缺失/重复有效分类、event 缺失/重复、posting 金额与分类不符、claim 非唯一/净额不符、退款+退回+核销超 gross、互转缺一侧/方向金额日期不一致、跨 org/项目错位），每条含 issue_code/refs/期望与实际。
  - 全部只读派生（复用既有 owner 具名服务/模型只读），不复制业务表为可编辑余额；不写会话缓存以外的持久状态。
- **口径**：金额整数分（SignedCnyCents）、分类/桥接语义以 PH-239 报告与 `verify_integrity` 现有断言为准；本片不改账本口径；`as_of` 仅作为只读过滤（不追溯重算历史）。
- **权限/门控**：owner/finance/auditor 可读全量；pm 仅其管理项目的现金流摘要且不含他人薪资/费率；member 拒绝；cash 模块停用后只读历史可读、写路由不适用；未登录 403。
- **幂等/审计**：只读接口无副作用、无收据；可选 generic audit `cash.bridge_snapshot.viewed`（actor/org/as_of，不含明细）由报告决定，不污染审计链。
- **明确不做**：新增/修改任何事实、迁移、canonical 事件/命令、自动更正、导出文件、账本/收入/成本/未清写、Offset 事实（PH-241 未 done）。
