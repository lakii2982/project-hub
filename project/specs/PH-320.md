# PH-320 · 发票实现首片：发票签发/价税分离/红冲负值（按 ADR 0015 落地）

## 开工资格、价值与范围

PH-319 规划槽消费；依赖 PH-293（发票 ADR 契约冻结，ready）与 PH-252（发票实现，proposed）、PH-214/PH-224/PH-232（done）。本片在 ADR 0015 冻结后实现发票最小写侧：发票签发（引用结算/收入/合同条款）、价税分离（税率快照/整数分/ROUND_HALF_UP）、红冲负值（append-only、不得编辑已签发）、只读列表/详情；**不做** PDF/邮件/客户门户、多币种、税额抵扣完整实现（PH-317 后续）。依赖未全部 done，故 proposed。

## 行为（冻结 DoR）

- **签发**：owner/finance 具名服务/浏览器；引用已生效结算/收入/条款；金额服务端派生，不接受客户端覆盖；request_token 收据；公司锁。
- **价税分离**：gross=net+tax；税率快照；税额整数分、ROUND_HALF_UP；不可抵扣税成本走 costing owner。
- **红冲**：已签发只能追加负值冲销（保留原 ref/来源），红冲≤原发票，不得重复红冲/直接编辑。
- **权限**：owner/finance 写；auditor 只读；pm 仅其项目摘要；member 拒绝；模块停用历史只读。
- **不写事实**：经既有 owner 命令；不新增 canonical topic/command 除非 ADR 已冻结；不改 contract schema。
- **明确不做**：PDF/邮件/门户、多币种、税额抵扣完整、导出。
