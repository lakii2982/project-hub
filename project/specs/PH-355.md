# PH-355 · 通知中心前置拆分：reminder refs 契约与到期扫描骨架（PH-301 拆分）

## 开工资格、价值与范围

PH-351 规划槽消费；PH-301 拆分。范围：冻结 reminder ref 形状（namespace/kind/id/severity/issue_code/refs/as_of）与到期扫描骨架（只读派生、按来源去重、幂等重试、权限过滤），**不做**站内收件箱写侧/邮件/短信/推送、自动审批/支付/锁账。依赖 PH-179/183/151 未 done，故 proposed。

## 行为（冻结 DoR）

- reminder ref：字段/来源/severity/issue_code/refs/as_of 冻结；跨 owner 只读引用，不复制事实。
- 扫描骨架：幂等扫描、按来源+kind 去重、失败重试不重复待办；权限/停用过滤。
- 零外部副作用：不发邮件/短信/Webhook、不自动业务动作；只读输出。
- 明确不做：收件箱写侧/已读状态（PH-301 后续）、外部渠道、审批/支付/锁账动作、新 canonical 实体。

## 模型与字段 / 迁移

- 不新增 canonical 模型/迁移；如需扫描游标由 PH-301/后续按实际 BASE 申请。
