# PH-287 · 合同收费模板/生效条款只读快照与结算核对首片（无写入口、无迁移）

## 开工资格、价值与范围

PH-286 规划槽消费；来源：PH-214（三模板合同批准/收费模板）、PH-265（合同变更/终止）、PH-224（结算未清）、PH-232（核销）、PH-219/PH-222（管理收入/结算配对）均 done。承接合同条款核对缺口：把「批准合同版本 ↔ 收费模板/条款行 ↔ 生效变更 ↔ 已生效结算/未清/收入」做成**只读快照与核对清单**，检查条款被变更后仍可结算、终止后仍读取条款、模板与条款金额不一致、合同行被重复消费等问题；**不做**任何写入口、不改合同/结算/收入事实、不新增 canonical 事件/命令、不做迁移、不实现发票/税额。

## 行为（冻结 DoR）

- **只读接口**：
  - `approved_terms_snapshot(member, *, contract_id, as_of=None)`：返回批准版本 ref/生效时间、收费模板（fixed_price/time_and_material/service_period）与条款行 refs/金额/税/质保、变更历史摘要、终止标记；分页上限 200。
  - `terms_settlement_issues(member, *, as_of=None)`：异常清单（条款未批准即被引用、终止后仍可结算/读取、条款金额与结算/未清不一致、同一条款行重复消费、跨 org/项目引用、变更后旧条款仍 active），每条含 issue_code/refs/期望与实际。
  - 全部只读派生（复用 contracts/settlement/management_revenue 既定具名接口），不复制业务表。
- **口径**：金额整数分；条款/模板语义以 PH-214 交付为准，终止守卫以 PH-265 为准，结算/收入以 PH-224/PH-219/PH-222 为准；`as_of` 仅只读过滤。
- **权限/门控**：owner/finance/auditor 可读全量；pm 仅其管理项目摘要；member 拒绝；contracts 模块停用后只读历史可读；未登录 403。
- **幂等/审计**：只读无副作用、无收据；可选 generic audit `contracts.terms_snapshot.viewed`。
- **明确不做**：合同/条款/结算/收入写、终止/变更动作、账本/现金/成本/未清写、发票/税额、迁移、canonical 新 topic、导出文件。

## 模型与字段 / 迁移

- 首片不新增业务表/迁移：按请求只读派生；复用批准合同版本/条款/结算/收入只读；不改已应用迁移（contracts 叶 0003）。
