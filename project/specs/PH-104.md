# PH-104 · 团队交付：独立复核、真实验收与PR检查

实现local-team.md第5节。独立复核必须另一run/agent且绑定base/contract/最终diff摘要；复核者只读工作目录。验收从可信BASE命令白名单执行，实际结果关联最终文件摘要；失败不生成完成证明。主控才能push/创建PR，Task唯一行、报告/交接齐全；用固定gh argv，PR头变化和CI缺失/失败阻止merge。首次交付到PR为默认终点；仅当前用户授权范围下由主控显式merge，重新查询远端8项requiredchecks、严格最新BASE、未解决讨论、review与最终head。无发布/部署命令。公开只允许任务/commit/PR/测试摘要，不上传原始私有日志。

完整接口与安全边界以 docs/engineering/local-team.md 为准。本任务不触及产品业务、生产数据或用户全局设置。共享状态与交付文档由整合者串行维护；worker只写其被进一步分配的代码/测试子集。

- `python scripts/projectctl.py check`
