# PH-025 - GPT对话主控：效果说明、结构化派工与恢复

Status, scope and dependencies: project/tasks.json. Source: user request dated 2026-10-23.

## Scope

GPT唯一主控，经桥与队列组织开发和反馈；保留用户本地订阅，不改全局Codex配置。

## Contract

下一规划先冻结实装exec/app-server协议、动作schema、允许动作、审批来源、会话游标/恢复。确定性层校验actor/contract/base/revision，不执行任意模型shell；常驻和开机启动分别授权。

See docs/engineering/ai-native-delivery.md for state, authorization, idempotency and trust boundaries. Product accounting, data schema and personal MCP are outside scope. Shared wiring is integrator-owned.

## Counterexamples

其他工具不可占controller身份；模型伪造approval拒绝；过期revision/契约拒绝；明确session恢复；配额/鉴权不足不转未知付费API。
