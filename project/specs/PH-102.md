# PH-102 · 本地四执行器：隔离运行、队列、取消和恢复

实现local-team.md第2/3节冻结API。私有SQLite、单机三并发、同scope排斥、run_id幂等、租约fencing、真实进程组身份、显式取消/超时与保守恢复。macOS先支持sandbox-exec，其他平台无有效后端返回config_required，禁止静默无隔离。四CLI固定argv，默认现有模型/登录，不拷贝凭据、不继承GitHub/SSH/其他提供方密钥、不用跳过权限参数。worker独立worktree、最小资料，不写共享Git/队列/其他目录。测试用假命令，另保留实机隔离验证。

完整接口与安全边界以 docs/engineering/local-team.md 为准。本任务不触及产品业务、生产数据或用户全局设置。共享状态与交付文档由整合者串行维护；worker只写其被进一步分配的代码/测试子集。

- `python -m unittest tests.test_delivery_execution tests.test_delivery_execution_queue tests.test_delivery_execution_sandbox tests.test_delivery_agents -v`
