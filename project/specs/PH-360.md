# PH-360 · 通知中心收件箱实现首片（PH-340 后续）

## 开工资格、价值与范围

PH-356 规划槽消费；接续 PH-340（通知中心实现首片）与 PH-344（通知中心契约前置）。本片实现站内待办/到期提醒收件箱最小写侧：按 owner 只读事实派生、按来源+kind 去重、权限过滤、已读/忽略状态、扫描幂等；**不做**邮件/短信/Webhook/外部推送、自动审批/支付/锁账、客户门户、新 canonical 实体。依赖 PH-340/PH-344 未 done，故 proposed。

## 行为（冻结 DoR）

- 提醒派生：只读既有 owner 事实（到期未清、待审/待复核、缺费率、备份失败等）；同事实+kind 去重；重试不重复。
- 收件箱：每成员只看自己提醒；已读/忽略最小状态；停用/权限收回后不可访问；模块停用保留历史与队列。
- 幂等/调度：扫描可重跑、并发扫描公司锁；不发外部消息、不自动业务动作。
- 权限：owner/finance/auditor 全量；pm 项目摘要；member 本人；跨 org 拒绝。
- 明确不做：外部渠道、审批/支付/锁账动作、客户门户、新 canonical topic/command。

## 模型与字段 / 迁移

- 复用既有通知/outbox/扫描模式；如需内部表按实际 BASE 在 core 内申请新迁移号，不改已应用迁移。
