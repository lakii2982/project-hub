# PH-274 · onboarding 导入预览实现前置：onboarding 插件 bootstrap 与 CSV 模板识别/字段-主数据映射只读预检

## 开工资格、价值与范围

PH-273 规划槽消费；来源 WP-IMPORT 与 ADR 0012（PH-267 done：新建 `pmo_plugins.onboarding` 插件作为导入/期初 owner）。本片是 PH-271（导入预览与冲突清单实现首片）的**前置收窄片**：只落地 onboarding 插件 bootstrap 与只读 CSV 模板识别/字段与主数据映射预检，**不做**冲突持久化（ImportConflict）、不做 normalized_commands、不做任何提交/期初，不依赖 PH-181/PH-185。依赖 PH-267（ADR 0012，done）、PH-002/PH-024（SDK/基础资料，done），全部 done，PH-273 规划槽据此晋级 ready。

**不做**：ImportConflict/ImportPreview 持久化、normalized_commands、逐域提交、期初批次/覆盖/事件、导入历史表、canonical 事件/命令、账本/现金/成本/收入/未清写、跨公司/批量并发提交、模板市场。本片不解除 PH-256/PH-271/PH-187–191 proposed。

## 行为（冻结 DoR）

- **插件 bootstrap（按 ADR 0012）**：新建 `pmo_plugins/onboarding` Django app；`plugin.py` manifest 恰好 8 字段（id=onboarding、name、version=0.1.0、kernel_api='>=1.0,<2'、requires={'contracts','settlement','cash'}、default_enabled=True、capabilities=[]、description）；注册到 `pmo/settings.py` 的 INSTALLED_APPS 与 PMO_PLUGIN_MODULES；`domain_metadata.py` 声明只读预览路由 access（owner/finance/auditor 可读，pm/member 拒绝）；页面经 `pmo_plugins/delivery/urls.py` root 单写绑定；本片不新增迁移（无业务表）。
- **只读预览服务**：`preview_import(member, *, kind, file_name, content)`：kind 必须属于既有 `core.imports.HEADERS` 白名单（只读复用，不修改 core）；解析 CSV 头（UTF-8/BOM、逗号分隔、空行忽略）；返回 `template`（识别到的 kind）、`columns`（表头）、`mapped_fields`（列→标准字段，未知列列入 unmapped）、`rows`（最多 200 行预览：行号/原值/标准化值/行级错误）、`row_errors`（逐行格式/必填/类型错误，含行号与字段）、`summary`（行数/错误数）；**零业务事实、零账本、零来源消费、零规范事件、零持久化**（不写 ImportPreview/ImportConflict 表，不写会话缓存以外的持久状态；本片甚至不写会话缓存，每次请求重新解析）。预览允许写一条 generic audit `onboarding.import_previewed`（含 kind/行数/错误数/actor，不含原始敏感值全文）。
- **字段映射与校验口径**：复用 `core.imports.HEADERS` 与既有导入预览的行级校验函数（只读调用；若需导出只读辅助，仅允许在 onboarding 内做薄包装，不改 core）；日期/金额/工时等按既有口径（整数分、整数分钟、Decimal）校验；未知/缺失必填列进入 row_errors；不猜测主数据 id，不做冲突裁决（留给 PH-271）。
- **权限/门控**：预览为只读；owner/finance/auditor 可读；pm/member 拒绝；onboarding 模块停用后历史页只读、写路由（无）不适用；未登录 403。
- **幂等/审计**：预览无副作用、无收据；同输入重复预览结果一致；generic audit 仅记录一次请求摘要（可按 request 粒度，不要求幂等键）。
- 明确不做：提交、期初、冲突持久化、normalized_commands、导入模板管理、批量/并发、跨公司。

## 模型与字段

- 不新增业务表、不新增迁移（无 `migrations/0001_initial.py`；app 仅 bootstrap）。不写 `SourceConsumption`/`AccountingEvent`/`LedgerPosting`/`ImportPreview`/`ImportConflict`/`OpeningBatch`。
- 复用 `core.imports.HEADERS`/`parse_csv`/`preview_rows` 的只读能力；不修改 core 代码（如需导出辅助，必须在 onboarding 内实现）。
- `pmo_plugins/delivery/urls.py`、`pmo/settings.py` 为 root 单写接线，仅新增 onboarding 注册与预览路由。

## 服务

- `preview_import(member, *, kind, file_name, content)`：权限/模块门控 → 解析/映射/逐行校验 → 返回只读投影（不写业务表）。
- 只读 `import_template_list(member)`：列出支持的导入 kind 与列模板（来自 HEADERS）。
- 不提供提交/冲突/期初服务。

## 权限与拒绝

- 读：owner/finance/auditor；pm/member 拒绝；模块停用后预览 403（历史页不适用）。
- 拒绝：未知 kind、非 CSV/超 1MB、空文件、缺必填列、非法 UTF-8、跨公司/未知字段注入、客户端传 normalized_commands/冲突结果/提交参数；所有拒绝零半笔（仅可能 generic audit）。
