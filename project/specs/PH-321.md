# PH-321 · 多币种实现首片：汇率快照/换算与只读展示（按 ADR 落地）

## 开工资格、价值与范围

PH-319 规划槽消费；依赖 PH-308（多币种 ADR，ready）与 PH-150/PH-155（legacy 合同/结算，proposed）。本片在 ADR 冻结后实现汇率快照（日期/来源/精度/版本）与合同/结算/收入只读换算展示；**不做**多币种账本、外币现金账户、汇兑损益、发票税额。依赖未全部 done，故 proposed。

## 行为（冻结 DoR）

- **汇率快照**：owner/finance 维护；按业务日期冻结、版本化、历史不可改；缺汇率 null+missing 不显示 0。
- **换算**：金额整数分；换算记录汇率 ref；ROUND_HALF_UP；不无迁移重算历史。
- **只读展示**：原币/记账币/汇率 ref 只读；不建可编辑余额。
- **权限**：owner/finance 写汇率；auditor 只读；pm 仅项目摘要；member 拒绝；模块停用历史只读。
- **明确不做**：多币种账本/外币现金/汇兑损益/发票税额/导出。
