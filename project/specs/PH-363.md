## 冻结摘要（PH-363 收口）

- 契约正文：`docs/v1.0-development/period-precheck-contract.md`（只读投影 `period.precheck.snapshot/v1`）。
- 输入：`period_precheck_snapshot(member, *, scope='company'|'project', project_id=None, period=None, as_of=None, sections=None)`；参数不携带金额/差额/状态。
- 输出：`precheck` 为**真实 canonical `PeriodPrecheck` 对象**（全部必填字段、完整 status 枚举、additionalProperties=false；警告只在 envelope `issues` 的 warning 中表达）+ envelope 顶层四类 `checks`/`differences`/`issues`/`missing`/`summary`/`precheck_digest`；扩展字段不进入 `precheck`，公开为 query 须 canonical version-bump。
- 四类核对唯一口径：cash `cash_bridge_snapshot`、settlement `open_item_coverage_snapshot`、revenue `revenue_pairing_snapshot`、cost `bank_charge_pairing`；issue_code 复用 owner 既有码，不新增第二套规则。
- 差额：`difference = expected - actual`（真实 0 才为 0）；任一侧缺失 → null + missing code；offset 未实现按 `offset_implemented=false` 呈现，不按 0。
- 期间/锁期：引用既有 AccountingPeriod/PeriodCloseRun/ProjectClose 只读事实；已关闭/锁定/未来日期/跨 org 为 blocker，未分类/缺税额/offset 未实现等为 warning。
- 权限：owner/finance/auditor 全量、pm 管理项目摘要、member 拒绝、停用 history_read；只读零写、无 audit/receipt。
- `precheck_digest`：sha256(canonical_json(contract/scope/period/as_of/watermark/issues/differences/missing))；PH-353 提交须服务端重算并拒绝 stale/blocked，客户端 digest 不作授权。
- 本片无实现/迁移/表/产品代码；PH-181/185 后续实现，PH-353 消费。
