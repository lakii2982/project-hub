# PH-106 · 修复GitHub桥的授权占键与错误Issue关联

修复审计F1/F2。首次授权绑定失败不占用业务幂等键；已发送操作仍按原unknown协议处理。unknown创建不得仅凭可复制marker关联远端Issue：必须同时核验精确标题/完整渲染正文和grant principal作为创建者；任何不确定保留unknown，不能向猜测对象更新。测试涵盖随机grant后合法grant、复制marker、错误作者/正文、响应丢失、重复/旧revision、鉴权拒绝。临时网络最多一次只读重试，不盲重发写。公开Issue被完整克隆仍不是远端exactly-once保证，保留该限制。
