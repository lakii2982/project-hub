# PH-358 · 发票批量导入实现首片（PH-338 后续）

## 开工资格、价值与范围

PH-356 规划槽消费；接续 PH-338（发票批量/导入后续）与 PH-342（发票批量/导入实现前置契约冻结）。本片在单张发票能力上实现批量登记首片：导入模板识别/字段映射、批量 `record_invoice` 与行/来源分配、同步冲突清单、同文件重试幂等、全有或全无提交；**不做**新 canonical 实体/topic、税务查验、PDF/邮件、多币种、批量红冲。依赖 PH-338/PH-342 未 done，故 proposed。

## 行为（冻结 DoR）

- 预检：模板/字段映射只读；错误行含行号/原因/原值；预览不落业务事实；权限/期间/锁期与单张一致。
- 批量提交：复用 `record_invoice`/`allocate_invoice_lines`，不复制价税/分配规则；公司锁+事务全有或全无；请求令牌/导入键幂等，重排不重复。
- 冲突：重复发票号、跨 org/项目、来源未批准/超核销、金额/税额不守恒逐条拒绝；错误清单可下载。
- 权限/门控：owner/finance 写；auditor 读；pm 项目摘要；member 拒绝；模块停用 history_read。
- 明确不做：新 canonical topic/command、税务查验、PDF/邮件、多币种、批量红冲、客户数据。

## 模型与字段 / 迁移

- 复用 invoicing/onboarding 既有服务；如需导入批次/行内部表，由本片按实际 BASE 在 onboarding 插件内申请新迁移号，不改已应用迁移。
