# PH-400 · 修复 Delivery arbitration 的 mergeable 元数据兼容性

来源：PR #258 真实 run `41266764258`，BASE policy/脚本报 `mergeable_required`；GitHub `pull_request` webhook 的 `mergeable` 可为 null，不能据此判定冲突或可合并。用户 2026-10-31 的完整 1.0 交付授权覆盖该研发门禁修复。

## 范围

- `.github/workflows/delivery.yml` 在只读权限下通过当前 PR REST API 获取 `mergeable`，并与 webhook 的 base/head SHA 交叉核对后生成供 BASE 脚本使用的元数据；不得信任候选修改的脚本/数据。
- 暂态 null 可做有限、短间隔重试；持续 null/false/未知仍 fail-closed。不得用 `mergeStateStatus=CLEAN` 阻断仲裁自身尚未完成的正常 PR，也不得把 null 当 true。
- 保留 `contents: read`、必要的 `pull-requests: read`、BASE policy/script、无候选代码执行和 bootstrap 边界。
- 补 `tests/test_delivery_policy.py` 对 null/false/SHA 不符的反例及 workflow 静态约束；真实 PR 验证后才可宣称兼容修复。不得启用 remote_checks_enforced 或修改仲裁规则。
