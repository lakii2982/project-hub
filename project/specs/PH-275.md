# PH-275 · 合同变更后续片：变更影响只读追溯与终止后新结算/变更阻断深化

## 开工资格、价值与范围

PH-273 规划槽消费；来源 PH-265（合同变更与终止首片，done（#155））的明确不做项与残留：变更对已过账结算/未清/收入的追溯调整、变更影响的可核查只读视图。依赖 PH-265（done）、PH-224（结算未清，done）、PH-232（核销，done）、PH-219/PH-222（管理收入/结算配对，done），全部 done，PH-273 规划槽据此晋级 ready。

承接合同变更后的**只读影响追溯**与**阻断深化**：为已生效合同变更提供只读影响清单（受影响合同行、已生效结算、未清项、管理收入确认），并确保终止后不得再创建新结算/新变更/新收入确认读取（复用既有 approved_terms_snapshot 终止守卫并补服务层显式守卫）；**不做**对已过账结算/未清/收入的重算或追溯调整（历史事实不改）、不做红冲/更正、不写账本/现金/成本/收入/未清、不新增 canonical topic/command、不改 contract schema。本片不解除 PH-150/PH-151/PH-155 proposed。

## 行为（冻结 DoR）

- **只读影响追溯**：`contract_change_impact(member, change_id)` 返回：变更 ref/类型/生效时间/前后版本 ref、受影响 contract_line refs、该合同行下已生效 Settlement/OpenItem/Clearance 计数与金额合计、引用该合同行的 RevenueRecognition（PH-219/PH-222）计数与金额合计、是否存在终止；全部只读投影，不写任何事实。`contract_change_impact_list(member, *, contract_id=None)` 按合同/变更列出影响摘要。
- **终止后阻断深化**：合同 terminated 且 `as_of >= terminated_on` 时：① `approved_terms_snapshot` 拒绝（PH-265 已有，本片只读校验不重复实现）；② 结算创建服务在调用 approved_terms_snapshot 前显式校验合同未终止（若 PH-265 已覆盖则只补测试与错误文案，不重复实现）；③ 变更草稿创建服务拒绝 terminated 合同；④ 管理收入/结算配对只读接口在终止后返回 `terminated=true` 标记而非静默读取。拒绝零半笔。
- **版本可追溯**：影响清单展示变更前 approved 版本与生效后新 approved 版本（termination 无新版本），只读、不可编辑；不自动重开旧版本。
- **权限/门控**：读 owner/finance/auditor；pm 仅其管理项目且只读摘要；member 拒绝；contracts 模块停用后只读历史页可读（history_read 路由）、写路由不适用；未登录 403。
- **幂等/审计**：只读接口无副作用、无收据；不写 generic audit（避免只读查询污染审计链）。
- 明确不做：历史结算/未清/收入重算、红冲/更正、客户确认流转、多币种、税额重算、发票、账本/现金/成本/收入写、删除历史。

## 模型与字段

- 不新增模型/迁移（contracts 叶保持 0003）；只读投影从既有 Contract/ContractVersion/ContractChange/Settlement/OpenItem/Clearance/RevenueRecognition 聚合。
- 不新增 canonical topic/command/schema；复用既有 refs 与事件。
- 不新增可编辑余额或桥表。

## 服务

- `contract_change_impact(member, change_id)`、`contract_change_impact_list(member, *, contract_id=None)`：只读聚合与权限/项目范围校验。
- 在既有 `save_contract_change_draft`（PH-265）与结算创建路径补 terminated 显式守卫（若已覆盖则仅补测试与错误文案，不改语义）。
- UI：合同详情/变更详情增加只读「变更影响」区（受影响结算/未清/收入计数与金额、终止标记）；不新增写入口。

## 权限与拒绝

- 读：owner/finance/auditor；pm 仅其管理项目摘要；member 拒绝；模块停用历史只读。
- 拒绝：跨公司/跨项目越权读取、终止后创建变更/结算、客户端传重算/调整参数、未知字段；所有拒绝零半笔。
