# PH-378 · 发票批量导入实现首片（PH-338/353 后续）

## 开工资格、价值与范围

PH-376 规划槽消费；接续 PH-338（发票批量/导入后续）与 PH-353（导入提交首片）。本片实现发票批量导入的**提交执行**：预览/字段映射/冲突清单已由 PH-274/PH-338/PH-353 提供；本片复用导入提交契约（PH-362）与 invoicing 具名服务（`record_invoice`/`allocate_invoice_lines`），完成批量登记/行分配/原子提交/幂等/错误 envelope；**不做**新 canonical 实体/topic、税务查验、PDF/邮件、多币种、批量红冲。依赖未 done，故 proposed。

## 行为（冻结 DoR）

- 提交只经持久预览（PH-353/PH-362），服务端重算 `precheck_digest`，拒绝 stale/blocked；客户端不传业务事实/冲突裁决。
- 批量登记复用 invoicing 具名服务，不复制价税/分配规则；单公司锁+单事务全有或全无；失败零半笔。
- `import_key`/`request_token` 幂等；同文件重排/重试不重复；改输入冲突；重复发票号/来源超额/金额守恒/税额未知逐行拒绝。
- 权限 owner/finance 写、auditor 读、pm 项目摘要、member 拒绝；模块停用 history_read；期间/锁期沿用 PH-362。
- 明确不做：新 canonical topic/command、税务查验、PDF/邮件、多币种、批量红冲、客户数据。

## 模型与字段 / 迁移

- 复用 onboarding 提交收据与 invoicing 服务；如需内部批次表由实现片按实际 BASE 在 onboarding/invoicing 申请新迁移号，不改已应用迁移。
