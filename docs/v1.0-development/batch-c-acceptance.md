## 4. 运维 runbook 骨架（V1-OPS-01–06）

责任人统一占位为角色：发布负责人、DBA、财务复核人、支持负责人、安全负责人（具体人员由运营在真实发布前填写，不写个人隐私）。

### V1-OPS-01 安装与诊断（Ubuntu24.04 + Compose v2）
- 前置：空机、固定版本、独立密钥/DB/卷；应用与 DB 不直接暴露公网。
- 步骤：环境检查→镜像/依赖→迁移→健康检查→初始管理员→隔离验证。
- 证据：命令、版本 SHA、日志摘要、端口/磁盘/镜像/迁移失败重试记录；`docs/verification.md` 条目。

### V1-OPS-02 TLS/安全
- 前置：真实域名、Caddy、Cookie/HSTS/代理边界。
- 步骤：证书签发/续期→错误配置拒绝→安全头验证。
- 证据：TLS 握手/头/续期演练记录；禁止只贴配置。

### V1-OPS-03 升级与兼容回退
- 前置：冻结基线、备份完成、迁移只追加。
- 步骤：备份→候选版本升级→迁移校验→冒烟→（必要时）仅在结构兼容时回退。
- 证据：升级前后 SHA、迁移列表、冒烟结果、回退演练记录；失败可恢复、不倒放账本。

### V1-OPS-04 备份与恢复
- 前置：PG + 非空附件一致快照。
- 步骤：快照→清单/哈希/权限/保留→隔离恢复→登录/报表/凭证/附件核对→RPO/RTO 记录。
- 证据：快照/哈希清单、恢复命令、核对结果、RPO/RTO 实测；禁止仅“备份任务存在”。

### V1-OPS-05 健康/容量/积压
- 步骤：健康检查→任务/队列积压→磁盘/备份失败→容量阈值→告警可操作诊断。
- 证据：健康输出、积压/磁盘/失败记录、基线环境与数据量；日志不含密码/令牌/薪酬。

### V1-OPS-06 PostgreSQL 多连接安全
- 前置：真实 PG、同一公司锁/行锁/版本/幂等。
- 步骤：双审批、超核销、退款、分摊、期初、锁账、发票红冲、汇率快照竞争各两连接时序。
- 证据：PG 版本、连接数、一胜一拒、无半笔、verify_integrity ok；SQLite 不作为并发证据。
