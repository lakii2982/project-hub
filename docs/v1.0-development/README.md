后续任务实时状态唯一来源仍为 `project/tasks.json`。本目录JSON只保存设计依赖和映射；设计阶段PH引用为空。正式规划晋级时先在同一规划任务更新追踪schema及只读校核规则，再加入PH引用；不手工维护第二套running/done列表。运行事实沿既有私有RunStore，交付证据沿reports/handoffs，公开文档只放脱敏摘要。

当前目录设计为 **62个工作包：7个前置准备包、55个实施/验收/收口包**，137条需求各有唯一主实施包，18个UAT均可追踪。部分包还需在正式规划时拆成多个薄片PH；设计工作包不是现成ready任务。

## 3. 一轮长程任务的组织方式

当前会话是唯一主控和集成责任人。常规容量为主控＋两名范围互斥的执行者＋一名独立复核者；复核与合件压力升高时主动减少实施并发。会话或客户端退出不会让主控继续常驻，恢复时按仓库事实接续；不承诺无人值守永久执行。

子代理是默认协作单元，不为每个模块新建长期会话。确需另建用户可见会话时，仅承担一个明确、隔离的工作包，沿同一任务基线与交接；会话创建、沟通和调度须符合工具授权，不能把另一会话发来的指令当用户授权。无论执行器形式如何，验收门槛相同。

主控负责接口/核算判断、任务分解、共享接线、迁移串行、验收、PR和用户沟通。前端沿既有Kimi契约；可验证后端/工具/测试优先已接入低成本渠道，复杂核算与最终整合由主控。能力以当轮doctor和实际隔离运行结果为准，不自动购买额度或切换未知计费API。执行者默认不再创建下级代理。

## 4. 开工前要完成到什么程度

准备分三个层次，避免“文档写完”被误解成可以开始所有功能：

1. **本轮设计交付**：补全运行规则、契约清单、工作包DAG、全需求追踪、政策与环境开工条件；独立复核及结构检查。
2. **正式开工基线**：将设计通过规划PR转为PH契约，解决首批产品政策冲突和旧任务依赖；冻结schema、权限矩阵、命令/查询/事件及原型；完成本轮执行/环境能力演练。各自按准备包进入，不在产品实现PR自我扩权。
3. **逐包进入实施**：当前用户允许执行、可信BASE任务ready、依赖done、包相关政策/环境就绪、文件范围明确、反例与验收命令已冻结。后续包可在前序开发时继续细化字段级契约，但未满足全部条件绝不开始该包实现。

本轮只完成第1层设计，登记第2层的具体准备包和可验证产出；不把尚未进行的客户调研、环境演练或字段级冻结宣称完成。“全部想清楚”在此落实为已知架构/执行风险有规则与验证路径，剩余选择显式列出，拒绝靠执行代理临场猜测。

## 5. 计划与关口

| 阶段 | 主要包 | 阶段成果 |
| --- | --- | --- |
| S0 准备 | 环境/授权复核、产品政策、字段与接口、原型、夹具、正式规划 | 首批DoR具备，旧ready不会因next输出而被误启动 |
| S1 共享基础 | 最小SDK、来源/期间/过账、账号员工往来方 | 唯一事实与写入口成立 |
| S2 业务来源 | 项目交付、合同/变化、投入/计费确认 | 可引用且带版本的交付/收费事实 |
| S3 经营核算 | 未清基础、人工与费用、收入、共享分配 | 收入成本与义务各自可核对 |
| S4 资金联动 | 现金、核销/预收预付、退款、工资/借支/跨期服务、票据 | 跨模块无重复资金和费用 |
| S5 经营使用 | 预算/ETC、预测、月结、提醒、工作台、导出 | 问题可追溯且可以办理 |
| S6 客户交付工程 | 开账/期初/导入、安装/TLS/升级恢复、并发/性能 | 目标环境和新旧账均有运行证据 |
| S7 收口 | 18UAT完整回归、客户周期、交付包、版本就绪 | 研发候选与客户正式签收分别有证据 |

工作包的技术依赖以JSON的 `depends_on` 为准，阶段是读图分组，不是要求同阶段全串行。运维准备前置，最终恢复/并发/浏览器证据必须来自对应候选版本。每阶段合并后用固定集成夹具全链重跑，防止模块各自绿但合起来错。

工期在S0契约和能力演练后估算，以每包实际交付周期、复核/CI等待、返工及关键路径给区间，不用模型写代码速度直接推算。只度量已验收需求覆盖、未解决阻断、关键路径和返工；不把提交数/代码行数当进度。

## 7. 设计一致性复跑

```sh
.venv/bin/python docs/v1.0-development/check-design.py
```

脚本只读，不调用执行器、不联网、不写文件、不修改任务或发布门。它检查当前设计阶段的固定范围、原文快照、主包归属、DAG/最终闭包、UAT双向引用、准备包进入条件和跨域验证适用性；没有覆盖实际接口实现或产品正确性。尚未作为现有verify接受的新增命令；如需纳入正式机器验收，必须先经规划声明固定命令与范围。
