# PR自主交付改造规划（PH-111）

基线：c1a1853（PR56），2026-10-27；实时GitHub仅owner协作者，8项required检查App15368、strict/admin/讨论/线性历史启用，approvals=0，自动合并关闭，无ruleset或environment，Actions默认read且禁止批准PR。此为当次审计，不是未来永久配置证明。

执行PH120契约与可信元数据仲裁、PH121客观CI与发布分离、PH122远端启用与真实演练。用户明确授权本轮工程实施与合入，但没有生产/付费/真实数据授权。三项各独立PR，先合入规划再按新BASE实施；已有八项检查不减少。本轮新增检查启用前如实写bootstrap，不能把候选工作流自报成功当作强制门禁。

无需新GitHub账号、外部App/服务或模型API，复用现有Codex Connector独立评论及本地隔离review。无可信独立结论或范围授权即阻断。管理员仍可改变仓库规则，个人OAuth可伪造人工声明，协议与独立机器人并非对仓库所有者的防篡改硬件。

每个交付报告包含需求与验收场景、范围/风险、真实测试/跳过、独立审查/局限、业务演示/环境、兼容性、迁移/恢复、未解决风险。机器仲裁报告只从实际API/收据推导“可合并/阻断”，不让worker自填pass替代测试，不把AI演示冒充人类业务确认。用户对冻结任务的范围授权允许AI按验收标准自主验收；不确定的业务口径仍升级。

计划不实现runtime，也不把此规划报告作为后续实现的验收证明。前端规范PH110及其源文件独立；原工作区未提交AGENTS/agent-protocol修改按另一次用户“仅本地”要求保留，不能复制上传。
